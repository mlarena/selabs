**Практическая работа №1: Сборка программы из исходников**

**Задание:**
1. Установите инструменты сборки.
2. Скачайте исходники программы.
3. Распакуйте архив.
4. Выполните `./configure`.
5. Объясните назначение configure.

**Решение и пояснения:**
```bash
sudo apt install -y build-essential
wget https://example.org/hello-1.0.tar.gz
tar -xzf hello-1.0.tar.gz
cd hello-1.0
./configure --prefix=/usr/local       # 4. Проверка окружения и настройка
```
**Пояснения:**
Исходники хранят в `/usr/src` или `/usr/local/src`. `configure` проверяет компилятор, библиотеки и создаёт Makefile. `--prefix` задаёт каталог установки. Распаковка — `tar -xzf` (gzip), `-xjf` (bzip2), `-xJf` (xz).

**Практическая работа №2: Компиляция и установка**

**Задание:**
1. Скомпилируйте программу.
2. Установите её в систему.
3. Проверьте установленный бинарник.
4. Удалите установленные файлы.
5. Объясните роли `make` и `make install`.

**Решение и пояснения:**
```bash
make                                  # 1. Компиляция
sudo make install                     # 2. Установка
which hello                           # 3. Проверка
sudo make uninstall                   # 4. Удаление (если поддерживается)
```
**Пояснения:**
`make` собирает программу по Makefile, `make install` копирует файлы в системные каталоги. `make uninstall` не всегда реализован — тогда удаляют файлы вручную. Установка из исходников обходит пакетный менеджер.

**Практическая работа №3: Патчи и параметры сборки**

**Задание:**
1. Установите утилиту `patch`.
2. Примените патч к исходникам.
3. Проверьте изменения.
4. Откатите патч.
5. Передайте параметры в configure.

**Решение и пояснения:**
```bash
sudo apt install -y patch
patch -p1 < fix.patch                 # 2. Применение патча
patch -p1 -R < fix.patch              # 4. Откат (-R)
./configure --prefix=/usr --enable-feature --with-lib=/usr/lib   # 5
```
**Пояснения:**
`patch` применяет изменения из diff-файла. `-p1` отбрасывает один уровень пути. `-R` откатывает патч. `configure` принимает множество опций (`--enable-*`, `--with-*`) для включения функций и указания путей.

**Практическая работа №4: Информация о системе при сборке**

**Задание:**
1. Определите архитектуру и версию ядра.
2. Найдите заголовки ядра.
3. Проверьте версии компилятора и make.
4. Установите программу с помощью `install`.
5. Объясните, зачем нужны заголовки ядра.

**Решение и пояснения:**
```bash
uname -m                              # 1. Архитектура
uname -r                              # 1. Версия ядра
ls /usr/src/linux-headers-$(uname -r) # 2. Заголовки ядра
gcc --version && make --version       # 3. Версии инструментов
sudo install -m 755 hello /usr/local/bin/hello   # 4. Установка
```
**Пояснения:**
Заголовки ядра (`linux-headers`) нужны для сборки модулей и программ, использующих внутренние API ядра. `install` копирует файлы с заданными правами и владельцем — удобнее `cp` при установке.
