# selabs

Учебный проект практических лабораторных работ по Linux (Debian) для подготовки к сертификации **Linux Professional Institute (LPI)**.

## Цели проекта

1. Дать структурированную программу обучения по уровням LPIC-1, LPIC-2, LPIC-3 Mixed Environments и LPIC-3 Security.
2. Закрепить теорию практическими работами с разбором решений.
3. Подготовить к реальным экзаменационным заданиям через «боевые задачи» (`exam.md`).

## Структура

```
selabs/
├── home.md                          # главный индекс
├── README.md                        # этот файл
├── docs/                            # документация проекта
│   ├── lpi-map.md                   # карта соответствия целям LPI
│   ├── roadmap.md                   # план развития
│   └── exam-format.md               # формат экзаменов
├── LPIC-1/                          # уровень LPIC-1 (101-500, 102-500)
│   └── <NNN_Тема>/                  # тема экзамена (101…110)
│       ├── <NNN.N_Объектив>/        # объектив (напр. 103.5_Process_Management)
│       │   └── task.md        # практические работы
│       └── exam.md                  # экзаменационные боевые задачи по теме
├── LPIC-2/                          # уровень LPIC-2 (201-450, 202-450)
├── LPIC-3-Mixed-Environments/       # уровень LPIC-3 (300-300)
├── LPIC-3-Security/                 # уровень LPIC-3 (303-300)
└── resources/                       # вспомогательные материалы и черновики
```

## Как учиться

1. Откройте `home.md` и выберите уровень.
2. В `home.md` уровня найдите тему и нужный объектив.
3. Выполните практические работы (`task.md`), сверяясь с решением и пояснениями.
4. Закрепите тему, решив боевые задачи (`exam.md`).

## Соглашения

- Язык материалов — русский; команды и имена файлов — латиницей.
- Все команды рассчитаны на Debian и не должны содержать кириллицы в консоли.
- Один объектив = один каталог; в нём практические работы. Боевые задачи — на уровне темы.
- Навигация между файлами — через ссылки вида `?file=<путь>`.

## Обратная связь

Проект развивается итеративно: добавляются новые лабораторные и боевые задачи. Список тем в работе — в `docs/roadmap.md`.
