# Формат экзаменов LPI

Справка по актуальным версиям экзаменов (на момент создания проекта).

## LPIC-1 — Linux Administrator

- **Версия:** 5.0
- **Экзамены:** 101-500 и 102-500 (нужно сдать оба).
- **Формат:** 60 вопросов (multiple-choice и fill-in-the-blank), 90 минут на каждый экзамен.
- **Предварительные требования:** нет.
- **Срок действия:** 5 лет.

### Темы экзамена 101-500

| Тема | Название |
| --- | --- |
| 101 | System Architecture |
| 102 | Linux Installation and Package Management |
| 103 | GNU and Unix Commands |
| 104 | Devices, Linux Filesystems, Filesystem Hierarchy Standard |
