**Практическая работа №1: Работа с ext2/3/4**

**Задание:**
1. Создайте ext4 на loop-устройстве.
2. Посмотрите суперблок и параметры.
3. Измените параметры через `tune2fs`.
4. Проверьте ФС через `e2fsck`.
5. Объясните разницу ext2/ext3/ext4.

**Решение и пояснения:**
```bash
sudo mkfs.ext4 /dev/loop0
sudo dumpe2fs -h /dev/loop0 | head            # 2. Суперблок
sudo tune2fs -L data /dev/loop0               # 3. Метка
sudo tune2fs -c 30 /dev/loop0                 # 3. Проверка каждые 30 монтирований
sudo e2fsck -f /dev/loop0                     # 4. Проверка
```
**Пояснения:**
ext2 — без журнала, ext3 — журналирование, ext4 — extents, большие тома, быстрее. `dumpe2fs` показывает параметры ФС, `tune2fs` меняет их без пересоздания, `e2fsck` проверяет и восстанавливает.

**Практическая работа №2: Работа с XFS**

**Задание:**
1. Создайте XFS на loop-устройстве.
2. Посмотрите информацию о ФС.
3. Выполните проверку XFS.
4. Дефрагментируйте ФС.
5. Сравните XFS и ext4.

**Решение и пояснения:**
```bash
sudo mkfs.xfs /dev/loop1
sudo xfs_info /dev/loop1                # 2. Информация
sudo xfs_repair -n /dev/loop1           # 3. Проверка (только чтение)
sudo xfs_fsr /mnt/xfs                   # 4. Дефрагментация
```
**Пояснения:**
XFS — высокопроизводительная журналируемая ФС, хорошо масштабируется, поддерживает онлайн-дефрагментацию (`xfs_fsr`). Проверка — `xfs_repair` (только на размонтированной ФС). ext4 проще и универсальнее, XFS лучше для больших файлов и параллельного I/O.

**Практическая работа №3: Btrfs: подтома и снимки**

**Задание:**
1. Создайте Btrfs на loop-устройстве.
2. Создайте подтом.
3. Создайте снимок подтома.
4. Смонтируйте снимок.
5. Объясните преимущества снимков.

**Решение и пояснения:**
```bash
sudo mkfs.btrfs /dev/loop2
sudo mount /dev/loop2 /mnt/btrfs
sudo btrfs subvolume create /mnt/btrfs/data       # 2. Подтом
sudo btrfs subvolume snapshot /mnt/btrfs/data /mnt/btrfs/data-snap   # 3
sudo btrfs subvolume list /mnt/btrfs              # 4. Список
```
**Пояснения:**
Btrfs — CoW-ФС с подтомами и мгновенными снимками. Снимок фиксирует состояние и не занимает места, пока данные не изменены. Btrfs поддерживает сжатие, контрольные суммы и многоустройственные массивы.

**Практическая работа №4: SMART-мониторинг дисков**

**Задание:**
1. Установите `smartmontools`.
2. Проверьте состояние диска.
3. Посмотрите атрибуты SMART.
4. Включите самотестирование.
5. Настройте демон `smartd`.

**Решение и пояснения:**
```bash
sudo apt install -y smartmontools
sudo smartctl -i /dev/sda               # 2. Информация
sudo smartctl -H /dev/sda               # 2. Общее состояние
sudo smartctl -A /dev/sda               # 3. Атрибуты
sudo smartctl -t short /dev/sda         # 4. Короткий тест
sudo systemctl enable --now smartd      # 5. Демон
```
**Пояснения:**
SMART предсказывает отказ диска по атрибутам (Reallocated_Sector_Ct, Pending_Sector и др.). `smartd` — демон, который периодически проверяет диски и уведомляет о проблемах. Важно для предотвращения потери данных.
