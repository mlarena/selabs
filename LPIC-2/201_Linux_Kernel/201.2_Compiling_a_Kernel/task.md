**Практическая работа №1: Конфигурирование ядра**

**Задание:**
1. Установите инструменты сборки.
2. Получите исходники ядра.
3. Создайте базовую конфигурацию на основе текущей.
4. Откройте конфигуратор `menuconfig`.
5. Сохраните конфигурацию.

**Решение и пояснения:**
```bash
sudo apt install -y build-essential libncurses-dev bison flex libssl-dev
sudo apt install -y linux-source
tar -xf /usr/src/linux-source-*.tar.xz -C /usr/src/
cd /usr/src/linux-source-*/
cp /boot/config-$(uname -r) .config    # 3. Базовая конфигурация
make olddefconfig                      # 3. Обновить под новую версию
make menuconfig                        # 4. Меню настройки
```
**Пояснения:**
Сборка ядра начинается с конфигурации `.config`. `make olddefconfig` обновляет старую конфигурацию, `make menuconfig` даёт текстовое меню. Можно использовать `config`, `xconfig`, `gconfig` — разные интерфейсы настройки.

**Практическая работа №2: Сборка ядра и модулей**

**Задание:**
1. Соберите ядро.
2. Соберите модули.
3. Установите модули.
4. Установите ядро.
5. Объясните, сколько ядер задействовать при сборке.

**Решение и пояснения:**
```bash
make -j$(nproc)            # 1. Сборка ядра (параллельно)
make modules               # 2. Сборка модулей
sudo make modules_install  # 3. Установка модулей
sudo make install          # 4. Установка ядра и обновление загрузчика
```
**Пояснения:**
`-j$(nproc)` использует все ядра CPU для ускорения. `modules_install` копирует модули в `/lib/modules/<версия>/`, `install` устанавливает ядро в `/boot` и обновляет конфигурацию GRUB. Цели `deb-pkg`/`rpm-pkg` создают пакеты.

**Практическая работа №3: initramfs и загрузчик**

**Задание:**
1. Создайте образ initramfs для нового ядра.
2. Проверьте содержимое initramfs.
3. Обновите конфигурацию GRUB.
4. Убедитесь, что новое ядро доступно в меню загрузки.
5. Объясните роль initramfs.

**Решение и пояснения:**
```bash
sudo update-initramfs -c -k $(uname -r)     # 1. Создание initramfs
ls -lh /boot/initrd.img-*                   # 2. Проверка
lsinitramfs /boot/initrd.img-$(uname -r) | head   # 2. Содержимое
sudo update-grub                            # 3. Обновление GRUB
grep menuentry /boot/grub/grub.cfg | head   # 4. Пункты меню
```
**Пояснения:**
initramfs — временная корневая ФС в памяти, монтирующая настоящий корень (LVM, RAID, шифрование) до запуска `init`. `update-initramfs` создаёт/обновляет образ. `update-grub` перестраивает меню загрузчика.

**Практическая работа №4: DKMS**

**Задание:**
1. Установите DKMS.
2. Проверьте список модулей под управлением DKMS.
3. Установите модуль через DKMS (например, из пакета).
4. Убедитесь, что модуль пересобирается при обновлении ядра.
5. Объясните преимущество DKMS.

**Решение и пояснения:**
```bash
sudo apt install -y dkms
dkms status                                  # 2. Модули DKMS
sudo dkms install <module>/<version>         # 3. Сборка и установка
sudo dkms status                             # 4. Проверка
```
**Пояснения:**
DKMS (Dynamic Kernel Module Support) автоматически пересобирает сторонние модули при обновлении ядра. Это решает проблему, когда модуль, собранный под старое ядро, перестаёт работать. Требуется наличие исходников/headers ядра.
