**Практическая работа №1: Сканирование портов и оценка поверхности атаки**

**Задание:**
1. Просканируйте локальный хост на открытые порты.
2. Определите версии служб.
3. Найдите потенциально опасные службы (telnet, ftp).
4. Проверьте доступность порта через `nc`.
5. Объясните, зачем проводить инвентаризацию портов.

**Решение и пояснения:**
```bash
nmap -sT localhost                       # 1. Открытые порты
nmap -sV localhost                       # 2. Версии служб
ss -tlnp                                 # 1. Слушающие порты и процессы
nc -zv localhost 23                      # 4. Проверка порта
```
**Пояснения:**
Регулярное сканирование выявляет неожиданно открытые порты и устаревшие службы. `nmap -sV` определяет версии (для оценки уязвимостей). Небезопасные службы (telnet, ftp) следует отключать или заменять (SSH, SFTP).

**Практическая работа №2: Fail2ban**

**Задание:**
1. Установите `fail2ban`.
2. Включите защиту SSH.
3. Настройте число попыток и время блокировки.
4. Проверьте статус jail.
5. Посмотрите заблокированные адреса.

**Решение и пояснения:**
```bash
sudo apt install -y fail2ban
# /etc/fail2ban/jail.local:
# [sshd]
# enabled = true
# maxretry = 3
# bantime = 3600
sudo systemctl enable --now fail2ban
sudo fail2ban-client status sshd         # 4. Статус
sudo fail2ban-client status sshd | grep Banned   # 5. Блокировки
```
**Пояснения:**
Fail2ban читает логи и блокирует IP после N неудачных попыток (через iptables/nftables). `jail.local` переопределяет настройки по умолчанию. `fail2ban-client` управляет и показывает статус «тюрем».

**Практическая работа №3: Обновления безопасности и уведомления**

**Задание:**
1. Проверьте доступные обновления безопасности.
2. Установите только обновления безопасности.
3. Настройте автообновления безопасности.
4. Проверьте подписи пакетов.
5. Объясните источники оповещений об уязвимостях.

**Решение и пояснения:**
```bash
sudo apt update
apt list --upgradable 2>/dev/null | grep -i security
sudo apt install -y unattended-upgrades
sudo dpkg-reconfigure -plow unattended-upgrades   # 3. Автообновления
apt-cache policy | grep -i security
```
**Пояснения:**
Своевременное применение патчей — базовая мера безопасности. `unattended-upgrades` автоматически ставит обновления безопасности. Источники оповещений: списки рассылки Debian Security, CVE/NVD, CERT, vendor-адвизори.

**Практическая работа №4: IDS на хосте (awareness)**

**Задание:**
1. Установите `rkhunter` (или `chkrootkit`).
2. Запустите проверку системы.
3. Проанализируйте отчёт.
4. Настройте регулярный запуск через cron.
5. Объясните назначение HIDS.

**Решение и пояснения:**
```bash
sudo apt install -y rkhunter chkrootkit
sudo rkhunter --update
sudo rkhunter --check --sk              # 2. Проверка
sudo chkrootkit | grep INFECTED
# cron: 0 3 * * * /usr/bin/rkhunter --check --sk
```
**Пояснения:**
HIDS (host-based IDS) выявляет rootkits и изменения системных файлов. `rkhunter`/`chkrootkit` проверяют известные сигнатуры. Сетевые IDS (Snort, OpenVAS) анализируют трафик и уязвимости. Регулярный запуск и анализ отчётов — обязательны.
