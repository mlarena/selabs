**Практическая работа №1: Базовые переменные окружения**

**Задание:**       
1. Создайте переменную `MY_NAME` со значением вашего имени.       
2. Создайте переменную `WORK_DIR` со значением `/var/tmp/test`.       
3. Выведите значения обеих переменных.       
4. Используя переменные, создайте директорию из `WORK_DIR` и файл внутри с именем из `MY_NAME`.       
5. Выведите список всех переменных окружения, отсортированный по алфавиту.
6. Удалите созданные переменные из текущей сессии.       

**Решение и пояснения:**
```bash
MY_NAME="Ivan"                     # 1. Создание переменной (без пробелов!)
WORK_DIR="/var/tmp/test"           # 2. Присвоение значения
echo $MY_NAME $WORK_DIR            # 3. Вывод значений
mkdir -p $WORK_DIR                 # 4. Создание директории (-p если нет)
touch $WORK_DIR/$MY_NAME.txt       # 4. Файл Ivan.txt в /var/tmp/test
env | sort                         # 5. Все переменные окружения (env)
unset MY_NAME WORK_DIR             # 6. Удаление переменных
```
**Пояснения:**       
Переменные создаются без `$`, используются с `$`.        
`echo` выводит значения.        
`env` показывает все переменные окружения.        
`unset` удаляет переменные. Кавычки важны при пробелах в значениях.

**Практическая работа №2: Переменные shell и подстановка**

**Задание:**        
1. Создайте переменную `TODAY` с текущей датой в формате ДД-ММ-ГГГГ.       
2. Создайте переменную `FILES_COUNT` с количеством файлов в `/etc`.       
3. Объедините эти переменные в строку "На [сегодняшняя дата] в /etc [количество] файлов".       
4. Создайте переменную `PATH_BACKUP` со значением `$PATH`.       
5. Добавьте `/home/user/bin` в начало `PATH`.       
6. Верните оригинальное значение `PATH` из `PATH_BACKUP`.       

**Решение и пояснения:**
```bash
TODAY=$(date +%d-%m-%Y)                        # 1. Подстановка вызова date
FILES_COUNT=$(ls /etc | wc -l)                 # 2. Подсчет файлов в /etc
REPORT="На $TODAY в /etc $FILES_COUNT файлов"  # 3. Объединение
echo $REPORT                                   # 4. Вывод: "На 25-12-2024 в /etc 157 файлов"
PATH_BACKUP="$PATH"                            # 5. Сохраняем текущий PATH
PATH="/home/user/bin:$PATH"                    # 6. Добавляем каталог в начало
echo $PATH                                     # 7. Проверка изменений
PATH="$PATH_BACKUP"                            # 8. Восстанавливаем оригинал
```
**Пояснения:**      
`$(команда)` подставляет вывод команды.      
`wc -l` считает строки.       
`$PATH` особенная переменная для поиска команд.       
Изменяя `PATH`, меняем порядок поиска программ.

**Практическая работа №3: Параметры и специальные переменные**

**Задание:**       
1. Напишите скрипт `script.sh`, который принимает 2 аргумента.      
2. В скрипте выведите: количество аргументов, первый аргумент, все аргументы.      
3. Запустите скрипт с аргументами `test1 test2`.      
4. В том же скрипте выведите PID текущего процесса и код возврата последней команды.      
5. Проверьте код возврата команд `ls` и `ls /несуществующий_каталог`.      
6. Создайте переменную, содержащую результат команды с ошибкой.      

**Решение и пояснения:**
```bash
#!/bin/bash
# script.sh:
echo "Аргументов: $#"              # 2. Количество аргументов
echo "Первый: $1"                  # 2. Первый аргумент
echo "Все: $@"                     # 2. Все аргументы
echo "PID: $$"                     # 4. PID текущего процесса
ls                                 # 5. Успешная команда
echo "Код возврата ls: $?"        # 4. Должен быть 0
ls /несуществующий_каталог        # 5. Команда с ошибкой
echo "Код возврата: $?"           # 5. Должен быть не 0
RESULT=$(ls /несуществующий 2>&1) # 6. Перехват stderr в переменную
```
**Пояснения:**       
`$#` — количество аргументов,        
`$1` — первый аргумент,        
`$@` — все аргументы.        
`$$` — PID процесса.        
`$?` — код возврата (0 = успех).        
`2>&1` перенаправляет stderr в stdout для записи в переменную.

**Практическая работа №4: Экспорт переменных и скрипты**

**Задание:**     
1. Создайте переменную `SHARED_VAR` со значением "shared".     
2. Экспортируйте переменную, чтобы она была доступна дочерним процессам.     
3. Напишите скрипт `check_var.sh`, который проверяет значение `SHARED_VAR`.     
4. Запустите скрипт и убедитесь, что он видит экспортированную переменную.     
5. Запустите скрипт в отдельной среде, где `SHARED_VAR` имеет другое значение.     
6. Создайте переменную `LOCAL_VAR` без экспорта и проверьте её доступность в скрипте.     

**Решение и пояснения:**
```bash
SHARED_VAR="shared"                # 1. Создание переменной
export SHARED_VAR                  # 2. Экспорт для дочерних процессов

# check_var.sh:
echo "SHARED_VAR: $SHARED_VAR"     # 3. Скрипт использует переменную

# Проверка:
bash check_var.sh                  # 4. Выведет "shared"
SHARED_VAR="different" bash check_var.sh  # 5. Временное изменение

LOCAL_VAR="local_only"             # 6. Без экспорта
bash -c 'echo $LOCAL_VAR'          # Не выведет ничего (переменная не видна)
```
**Пояснения:**        
`export` делает переменную доступной в дочерних процессах. Без экспорта переменная только в текущем shell.       
`VAR=value command` временно меняет переменную только для этой команды.       
Экспортированные переменные наследуются всеми дочерними процессами.
