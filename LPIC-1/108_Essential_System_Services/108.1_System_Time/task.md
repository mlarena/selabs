**Практическая работа №1: Системное время и часовой пояс**

**Задание:**
1. Выведите текущее системное время и дату.
2. Проверьте состояние синхронизации времени.
3. Установите часовой пояс `Europe/Moscow`.
4. Включите автоматическую синхронизацию времени.
5. Проверьте аппаратные часы.

**Решение и пояснения:**
```bash
date                                    # 1. Системное время
timedatectl status                      # 2. Состояние и синхронизация
sudo timedatectl set-timezone Europe/Moscow   # 3. Часовой пояс
sudo timedatectl set-ntp true           # 4. Автосинхронизация
hwclock --show                          # 5. Аппаратные часы
```
**Пояснения:**
`timedatectl` — основной инструмент управления временем в systemd. `set-ntp true` включает синхронизацию через systemd-timesyncd (или chrony/ntpd). Аппаратные часы обычно хранят время в UTC.

**Практическая работа №2: Настройка chrony**

**Задание:**
1. Установите `chrony`.
2. Добавьте сервер `pool.ntp.org` в конфигурацию.
3. Запустите и включите службу.
4. Проверьте источники времени.
5. Посмотрите, синхронизированы ли часы.

**Решение и пояснения:**
```bash
sudo apt install -y chrony                       # 1. Установка
sudo tee -a /etc/chrony/chrony.conf >/dev/null <<'EOF'
pool pool.ntp.org iburst
EOF
sudo systemctl enable --now chrony               # 3. Запуск и автозапуск
chronyc sources -v                               # 4. Источники времени
chronyc tracking                                 # 5. Состояние синхронизации
```
**Пояснения:**
chrony — современная реализация NTP. `pool pool.ntp.org iburst` добавляет пул серверов времени. `chronyc sources` показывает источники и их состояние (`^*` — выбранный), `chronyc tracking` — смещение и точность.

**Практическая работа №3: NTP и ntpq**

**Задание:**
1. Установите классический `ntp`.
2. Настройте серверы времени в `/etc/ntp.conf`.
3. Запустите службу.
4. Проверьте синхронизацию через `ntpq`.
5. Объясните разницу между ntpd и chrony.

**Решение и пояснения:**
```bash
sudo apt install -y ntp
sudo sed -i 's/^pool.*/pool pool.ntp.org iburst/' /etc/ntp.conf
sudo systemctl enable --now ntp
ntpq -p                          # 4. Список peers и их состояние
ntpdate -q pool.ntp.org          # Разовая проверка
```
**Пояснения:**
`ntpd` — классический демон NTP. `ntpq -p` показывает список серверов (peers) и их параметры; символ `*` означает текущий выбранный источник. chrony лучше работает при нестабильной сети и быстрее синхронизируется.

**Практическая работа №4: Ручная установка времени**

**Задание:**
1. Временно отключите автосинхронизацию.
2. Установите время вручную.
3. Синхронизируйте аппаратные часы с системными.
4. Включите автосинхронизацию обратно.
5. Объясните, почему ручная установка нежелательна.

**Решение и пояснения:**
```bash
sudo timedatectl set-ntp false                          # 1. Отключить NTP
sudo timedatectl set-time "2026-01-01 12:00:00"         # 2. Установка времени
sudo hwclock --systohc                                  # 3. Система -> аппаратные часы
sudo timedatectl set-ntp true                           # 4. Включить NTP
```
**Пояснения:**
Для ручной установки нужно сначала отключить NTP, иначе он перезапишет время. `hwclock --systohc` записывает системное время в аппаратные часы, `--hctosys` — наоборот. Ручная установка приводит к дрейфу и проблемам с логами, Kerberos и сертификатами.
