**Практическая работа №1: Характеристики дисков и интерфейсов**

**Задание:**
1. Определите тип дисков в системе.
2. Посмотрите информацию о NVMe-устройстве.
3. Проверьте поддержку TRIM.
4. Выполните TRIM вручную.
5. Объясните разницу SATA/NVMe и роль TRIM.

**Решение и пояснения:**
```bash
lsblk -d -o NAME,ROTA,SIZE,MODEL          # 1. ROTA=0 для SSD
sudo nvme list                             # 2. NVMe-устройства
sudo hdparm -I /dev/sda | grep -i trim     # 3. Поддержка TRIM
sudo fstrim -av                            # 4. TRIM для всех ФС
```
**Пояснения:**
NVMe — современный протокол для SSD по PCIe (быстрее SATA). TRIM сообщает SSD о неиспользуемых блоках для внутренней оптимизации. `fstrim` запускается периодически (таймер `fstrim.timer`).

**Практическая работа №2: Настройка параметров диска**

**Задание:**
1. Посмотрите текущие параметры диска.
2. Измените параметр кэширования записи.
3. Проверьте состояние планировщика I/O.
4. Измените планировщик для SSD.
5. Объясните влияние планировщика на производительность.

**Решение и пояснения:**
```bash
sudo hdparm -W /dev/sda                    # 1. Кэш записи
sudo hdparm -W 1 /dev/sda                  # 2. Включить кэш
cat /sys/block/sda/queue/scheduler         # 3. Планировщик
echo none | sudo tee /sys/block/nvme0n1/queue/scheduler   # 4. Для NVMe
```
**Пояснения:**
`hdparm` управляет параметрами ATA-дисков. Планировщик I/O (`mq-deadline`, `bfq`, `none`) влияет на порядок обработки запросов. Для NVMe обычно оптимален `none`; для HDD — `bfq`/`mq-deadline`.

**Практическая работа №3: iSCSI (awareness и настройка)**

**Задание:**
1. Установите iSCSI-инициатор.
2. Включите службу `iscsid`.
3. Обнаружьте iSCSI-цель.
4. Войдите в цель.
5. Посмотрите новое блочное устройство.

**Решение и пояснения:**
```bash
sudo apt install -y open-iscsi
sudo systemctl enable --now iscsid
sudo iscsiadm -m discovery -t sendtargets -p 192.168.1.10   # 3. Обнаружение
sudo iscsiadm -m node --login                                # 4. Вход
lsblk                                                        # 5. Новый диск
```
**Пояснения:**
iSCSI передаёт блочные устройства по TCP/IP (SAN). `iscsiadm` управляет обнаружением и подключением к целям. WWID/WWN идентифицируют устройства. SAN — сеть хранения (протоколы iSCSI, AoE, FCoE).

**Практическая работа №4: Анализ ресурсов устройства**

**Задание:**
1. Посмотрите прерывания IRQ.
2. Определите, какие IRQ используют диски.
3. Посмотрите очереди I/O.
4. Настройте параметры очереди.
5. Объясните назначение `sdparm`.

**Решение и пояснения:**
```bash
cat /proc/interrupts | head                # 1. Прерывания
grep -i nvme /proc/interrupts              # 2. IRQ дисков
ls /sys/block/sda/queue/                   # 3. Параметры очереди
cat /sys/block/sda/queue/nr_requests       # 3. Глубина очереди
sudo sdparm --all /dev/sda | head          # 5. SCSI-параметры
```
**Пояснения:**
`/proc/interrupts` показывает распределение прерываний по CPU. Параметры очереди (`nr_requests`, `read_ahead_kb`) влияют на производительность. `sdparm` читает/меняет SCSI-параметры (режимные страницы) устройств.
