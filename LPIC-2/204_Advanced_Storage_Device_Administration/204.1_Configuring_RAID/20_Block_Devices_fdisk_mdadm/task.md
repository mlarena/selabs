**Практическая работа №1: Работа с fdisk - создание разделов**      

**Задание:**      
1. Определите имя незанятого диска (например, /dev/sdb).      
2. Создайте на диске новый раздел размером 500MB.      
3. Создайте второй раздел, занимающий оставшееся место.      
4. Измените тип первого раздела на Linux LVM (код 8e).      
5. Запишите изменения и проверьте таблицу разделов.      
6. Отформатируйте разделы в файловые системы ext4.      

**Решение и пояснения:**
```bash
lsblk                                 # 1. Просмотр блочных устройств
sudo fdisk /dev/sdb                   # 2. Запуск fdisk
# Внутри fdisk:
n → p → 1 → Enter → +500M             # 2. Создание основного раздела 500MB
n → p → 2 → Enter → Enter             # 3. Второй раздел на всё оставшееся
t → 1 → 8e                            # 4. Изменение типа первого раздела на LVM
p                                     # Просмотр таблицы разделов
w                                     # 5. Запись изменений
sudo mkfs.ext4 /dev/sdb1              # 6. Форматирование первого раздела
sudo mkfs.ext4 /dev/sdb2              # 6. Форматирование второго раздела
```
**Пояснения:**       
В `fdisk`:       
`n` — новый раздел,       
`p` — основной раздел,       
`t` — изменение типа,       
`p` — просмотр,       
`w` — запись.       
После записи может потребоваться `partprobe` для обновления информации о разделах.       

**Внимание:**       
Убедитесь, что работаете с правильным диском, данные будут уничтожены.

**Практическая работа №2: Создание RAID-массива mdadm (RAID 1)**      

**Задание:**      
1. Установите утилиту mdadm.      
2. Создайте RAID 1 (зеркало) из двух разделов (/dev/sdb1, /dev/sdc1).
3. Проверьте статус созданного RAID.      
4. Добавьте раздел как горячий запас (spare).      
5. Сымитируйте отказ диска и проверьте восстановление.      
6. Создайте файловую систему на RAID и смонтируйте его.      

**Решение и пояснения:**
```bash      
sudo apt install mdadm -y            # 1. Установка mdadm
sudo mdadm --create /dev/md0 --level=1 --raid-devices=2 /dev/sdb1 /dev/sdc1  # 2. Создание RAID 1
cat /proc/mdstat                     # 3. Проверка статуса (посмотрите прогресс)
sudo mdadm --add /dev/md0 /dev/sdd1  # 4. Добавление spare-диска
sudo mdadm --fail /dev/md0 /dev/sdb1 # 5. Имитация отказа диска
watch cat /proc/mdstat               # 5. Наблюдение за восстановлением (Ctrl+C для выхода)
sudo mkfs.ext4 /dev/md0              # 6. Создание ФС
sudo mount /dev/md0 /mnt/raid        # 6. Монтирование
```

**Пояснения:** 
RAID 1 — зеркалирование, данные дублируются на всех дисках.       
`--level=1` указывает тип RAID. 
`--raid-devices=2` — количество активных дисков. 
`/proc/mdstat` показывает состояние RAID массивов. 
Hot spare автоматически заменит вышедший из строя диск.

**Практическая работа №3: Управление RAID-массивом**

**Задание:**
1. Просмотрите детальную информацию о RAID-массиве.      
2. Сохраните конфигурацию RAID в файл.      
3. Остановите RAID-массив.      
4. Соберите массив заново, используя сохраненную конфигурацию.      
5. Увеличьте размер RAID-массива, добавив диск.      
6. Проверьте целостность данных на массиве.      

**Решение и пояснения:**
```bash
sudo mdadm --detail /dev/md0         # 1. Детальная информация
sudo mdadm --detail --scan | sudo tee -a /etc/mdadm/mdadm.conf  # 2. Сохранение конфигурации
sudo mdadm --stop /dev/md0           # 3. Остановка массива
sudo mdadm --assemble /dev/md0       # 4. Сборка массива из конфигурации
sudo mdadm --add /dev/md0 /dev/sde1  # 5. Добавление нового диска
sudo mdadm --grow /dev/md0 --raid-devices=3  # 5. Увеличение количества дисков
sudo mdadm --detail /dev/md0 | grep "State :"  # 6. Проверка состояния
```
**Пояснения:**       
Конфигурация сохраняется в `/etc/mdadm/mdadm.conf` для автоматической сборки при загрузке.       `--grow` позволяет изменить параметры массива (требует поддержки ядром).       
После добавления диска в RAID 1 размер не увеличится, так как это зеркало.

**Практическая работа №4: Удаление RAID и разделов**

**Задание:**      
1. Размонтируйте RAID-массив.      
2. Пометить все диски в массиве как вышедшие из строя (failed).      
3. Удалить диски из массива.      
4. Остановить и удалить RAID-массив.      
5. Стереть superblock RAID с дисков.      
6. Удалить таблицу разделов с дисков.      

**Решение и пояснения:**      
```bash
sudo umount /dev/md0                 # 1. Размонтирование
sudo mdadm --fail /dev/md0 /dev/sdb1 /dev/sdc1  # 2. Пометить диски как failed
sudo mdadm --remove /dev/md0 /dev/sdb1 /dev/sdc1  # 3. Удалить диски из массива
sudo mdadm --stop /dev/md0           # 4. Остановить массив
sudo mdadm --zero-superblock /dev/sdb1 /dev/sdc1  # 5. Стереть superblock
sudo wipefs -a /dev/sdb              # 6. Очистить весь диск (или fdisk для удаления разделов)
```
**Пояснения:**       
`--zero-superblock` удаляет метаданные RAID с дисков, после этого их можно использовать заново.       
`wipefs -a` удаляет все подписи файловых систем.       

**Внимание:**       
Эти операции уничтожают данные. 
Перед удалением убедитесь, что нужные данные сохранены и вы работаете с правильными устройствами.
