**Практическая работа №1: Базовый поиск и фильтрация**

**Задание:**   
1. Создайте тестовый файл `log.txt` с данными (пример ниже).        
2. Найдите все строки, содержащие слово "error".      
3. Найдите строки, содержащие "error" или "ERROR".     
4. Выведите строки, НЕ содержащие "success".    
5. Подсчитайте количество строк с "error".     
6. Выведите номера строк, содержащих "warning".     

**Решение и пояснения:**
```bash
# 1. Создание тестового файла
echo -e "2024-01-15 INFO: System started\n2024-01-15 ERROR: Disk full\n2024-01-15 WARNING: High memory usage\n2024-01-15 INFO: Backup completed\n2024-01-15 ERROR: Network timeout\n2024-01-15 SUCCESS: Update installed" > log.txt

# 2. Поиск "error"
grep "error" log.txt

# 3. Поиск "error" или "ERROR" (игнорирование регистра)
grep -i "error" log.txt

# 4. Исключение строк с "success"
grep -v "success" log.txt

# 5. Подсчет строк с "error"
grep -c "error" log.txt

# 6. Номера строк с "warning"
grep -n "warning" log.txt
```
**Пояснения:** 
`grep` (Global Regular Expression Print) ищет паттерны в тексте.     
`-i` игнорирует регистр.         
`-v` инвертирует поиск (выводит строки, НЕ содержащие паттерн).        
`-c` подсчитывает совпадения.      
`-n` показывает номера строк.     
По умолчанию поиск регистрозависимый.

**Практическая работа №2: Расширенный поиск с регулярными выражениями**

**Задание:**
1. Найдите строки, начинающиеся с даты (формат ГГГГ-ММ-ДД).    
2. Найдите строки, заканчивающиеся точкой.     
3. Найдите IP-адреса в формате XXX.XXX.XXX.XXX.    
4. Найдите слова, состоящие только из цифр.      
5. Используйте группировку для поиска "error" или "warning".      
6. Найдите строки с повторяющимися словами.     

**Решение и пояснения:**
```bash
# 1. Строки, начинающиеся с даты
grep "^[0-9]\{4\}-[0-9]\{2\}-[0-9]\{2\}" log.txt  

# 2. Строки, заканчивающиеся точкой
grep "\\.$" log.txt

# 3. Поиск IP-адресов (упрощенный)
echo "IP: 192.168.1.1, 10.0.0.1" | grep -E "[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+"

# 4. Слова только из цифр
echo "test 123 abc 456" | grep -o "\b[0-9]\+\b"

# 5. "error" или "warning"
grep -E "error|warning" log.txt

# 6. Повторяющиеся слова (следующие подряд)
echo "hello hello world" | grep -E "\b(\w+)\b\s+\b\1\b"
```
**Пояснения:**      
`^` — начало строки,     
`$` — конец строки.      `[0-9]` — любая цифра.      
`\{4\}` — ровно 4 повторения.      
`\.` — экранированная точка.       
`-E` включает расширенные регулярки.      
`|` — логическое ИЛИ.      
`\b` — граница слова.      
`\w` — буквенно-цифровой символ.      
`\1` — ссылка на первую группу.

**Практическая работа №3: Поиск в файлах и директориях**

**Задание:**    
1. Найдите слово "root" во всех файлах в `/etc`.     
2. Рекурсивно поищите "config" во всех файлах текущей директории.     
3. Найдите файлы, содержащие "password" (игнорируя регистр).     
4. Выведите только имена файлов с совпадениями.     
5. Исключите определенные файлы из поиска (например, `.log`).    
6. Найдите совпадения в сжатых файлах (`.gz`).      

**Решение и пояснения:**
```bash
# 1. Поиск "root" в /etc (первые 5 результатов)
grep "root" /etc/* 2>/dev/null | head -5

# 2. Рекурсивный поиск "config"
grep -r "config" . 2>/dev/null | head -5

# 3. Поиск "password" (регистронезависимо) в /etc
grep -ri "password" /etc 2>/dev/null | head -5

# 4. Только имена файлов
grep -rl "root" /etc 2>/dev/null | head -5

# 5. Исключение .log файлов
grep -r "error" . --exclude="*.log" 2>/dev/null | head -5

# 6. Поиск в сжатых файлах
zgrep "error" /var/log/*.gz 2>/dev/null | head -5
```
**Пояснения:**        
`-r` рекурсивный поиск в директориях.      
`-l` показывает только имена файлов с совпадениями.      
`--exclude` исключает файлы по шаблону.      
`zgrep` работает с gzip-файлами.       
`2>/dev/null` скрывает ошибки доступа.            
При поиске в системных директориях могут потребоваться права sudo.

**Практическая работа №4: Контекст и расширенные опции**

**Задание:**     
1. Найдите "error" и покажите 2 строки до совпадения.   
2. Найдите "error" и покажите 2 строки после совпадения.    
3. Показывайте 1 строку до и после совпадения.     
4. Выделите найденное слово цветом в выводе.    
5. Ищите точное слово (целые слова).     
6. Найдите максимальное количество совпадений в файле.    

**Решение и пояснения:**
```bash
# 1. 2 строки до совпадения
grep -B 2 "error" log.txt

# 2. 2 строки после совпадения
grep -A 2 "error" log.txt

# 3. 1 строка до и после
grep -C 1 "error" log.txt

# 4. Цветной вывод
grep --color=auto "error" log.txt

# 5. Точное слово "error" (не "errors")
grep -w "error" log.txt

# 6. Ограничить количество совпадений
grep -m 2 "error" log.txt

# Дополнительно: показать только совпадающую часть
echo "error: disk full" | grep -o "disk.*"
```
**Пояснения:**     
`-B` (before),       
`-A` (after),      
`-C` (context) показывают контекст вокруг совпадения.       
`--color` подсвечивает найденный текст.      
`-w` ищет целые слова.      
`-m` ограничивает количество выводимых совпадений.      
`-o` показывает только совпадающую часть строки.      
Эти опции полезны для анализа логов.
