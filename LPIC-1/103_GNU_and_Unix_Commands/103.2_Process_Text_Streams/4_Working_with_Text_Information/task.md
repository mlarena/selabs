**Практическая работа №1: Поиск и фильтрация текста (grep)**

**Практическая работа №1:**

**Задание:**      
1. Скачайте файл `access.log` с 10 строками логов (примеры в решении).      
2. Найдите все строки, содержащие "GET" (регистрозависимо).      
3. Найдите строки с "404" или "500" кодами.      
4. Найдите строки с "admin", игнорируя регистр.      
5. Подсчитайте количество строк, содержащих "POST".      
6. Выведите строки, НЕ содержащие "127.0.0.1".      

**Решение и пояснения:**      
```bash
echo -e "127.0.0.1 GET /index.html 200\n192.168.1.1 POST /login 200\n127.0.0.1 GET /admin 404\n10.0.0.1 GET /test 500\n192.168.1.2 POST /data 200\n127.0.0.1 GET /admin 200\n10.0.0.2 GET /home 404\n192.168.1.3 POST /submit 200\n127.0.0.1 GET /api 500\n192.168.1.4 GET /user 200" > access.log

grep "GET" access.log                     # 2. Поиск GET
grep -E "404|500" access.log              # 3. ИЛИ через -E
grep -i "admin" access.log                # 4. -i игнорирует регистр
grep -c "POST" access.log                 # 5. -c считает совпадения
grep -v "127.0.0.1" access.log            # 6. -v инвертирует поиск
```
**Пояснения:** 
`grep` ищет паттерны. 
`-E` включает расширенные регулярки для "или".       
`-i` делает поиск регистронезависимым.       
`-c` показывает количество совпадений.       
`-v` выводит строки, НЕ содержащие паттерн.

**Практическая работа №2: Обработка текста (cut, sort, uniq)**

**Задание:**
1. Используйте файл `access.log` из предыдущей работы.      
2. Извлеките только IP-адреса (первая колонка).      
3. Отсортируйте IP-адреса по алфавиту.      
4. Удалите дубликаты IP-адресов.      
5. Подсчитайте, сколько запросов с каждого IP.      
6. Отсортируйте по количеству запросов (по убыванию).      

**Решение и пояснения:**      
```bash
cut -d' ' -f1 access.log                               # 2. Извлечь первую колонку (разделитель пробел)
cut -d' ' -f1 access.log | sort                        # 3. Сортировка
cut -d' ' -f1 access.log | sort -u                     # 4. Уникальные адреса (-u)
cut -d' ' -f1 access.log | sort | uniq -c              # 5. Подсчет частоты
cut -d' ' -f1 access.log | sort | uniq -c | sort -nr   # 6. Сортировка по числу
```
**Пояснения:** 
`cut -d' ' -f1` режет по пробелу, берет первое поле.       
`sort` сортирует строки.       
`sort -u` = уникальные.       
`uniq -c` подсчитывает повторения (требует отсортированный ввод).       
`sort -nr` сортирует численно и в обратном порядке.

**Практическая работа №3: Замена и преобразование (sed)**

**Задание:**      
1. Создайте файл `config.txt` с текстом (пример в решении).      
2. Замените "http" на "https" во всем файле.      
3. Удалите все строки, содержащие "debug".      
4. Замените "port 80" на "port 443" только в первых 3 строках.      
5. Удалите все комментарии (строки, начинающиеся с #).      
6. Покажите только строки с 3 по 5.      

**Решение и пояснения:**
```bash
echo -e "server http://example.com\nport 80\n# debug mode\ndebug true\nport 80\n# end config" > config.txt

sed 's/http/https/g' config.txt            # 2. Замена во всем файле
sed '/debug/d' config.txt                  # 3. Удаление строк с debug
sed '1,3 s/port 80/port 443/' config.txt   # 4. Замена в диапазоне строк
sed '/^#/d' config.txt                     # 5. Удаление строк, начинающихся с #
sed -n '3,5p' config.txt                   # 6. Показ только строк 3-5
```
**Пояснения:** `sed 's/что/на_что/g'` заменяет текст. `'/паттерн/d'` удаляет строки. `'1,3 s/...'` применяет замену к строкам 1-3. `'/^#/d'` удаляет строки, начинающиеся с `#`. `-n` с `p` показывает только указанные строки.

**Практическая работа №4: Анализ текста (awk)**

**Задание:**      
1. Используйте `access.log` из работы №1.      
2. Выведите только столбцы 1 (IP) и 4 (путь).      
3. Подсчитайте общее количество запросов.      
4. Найдите средний размер кода ответа (последняя колонка).      
5. Выведите уникальные пути (столбец 4).      
6. Напечатайте строки, где код ответа > 400.      

**Решение и пояснения:**
```bash
awk '{print $1, $4}' access.log                                # 2. Вывод 1-го и 4-го полей
awk 'END {print "Всего:", NR}' access.log                      # 3. NR = кол-во строк
awk '{sum+=$NF} END {print "Среднее:", sum/NR}' access.log     # 4. $NF = последнее поле
awk '{print $4}' access.log | sort -u                          # 5. Уникальные пути
awk '$NF > 400' access.log                                     # 6. Сравнение последнего поля
```
**Пояснения:** `awk` автоматически разбивает строки по пробелам.       
`$1` — первое поле,       
`$NF` — последнее.       
`NR` — номер текущей строки (в конце = всего строк).       
`END` выполняет команды после обработки всех строк. Условия без действия выводят всю строку.
