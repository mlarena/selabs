**Практическая работа №1: Полное и частичное резервное копирование**

**Задание:**
1. Определите каталоги, обязательные для бэкапа.
2. Создайте полный архив `/etc`.
3. Создайте частичный архив (только изменённые файлы).
4. Проверьте целостность архива.
5. Объясните, что нужно включать в бэкап.

**Решение и пояснения:**
```bash
tar -czf /backup/etc_full.tar.gz /etc          # 2. Полный бэкап
find /home -mtime -1 -print0 | tar -czf /backup/home_inc.tar.gz --null -T -   # 3
tar -tzf /backup/etc_full.tar.gz >/dev/null && echo OK   # 4. Проверка
```
**Пояснения:**
В бэкап включают `/etc`, `/home`, `/var` (данные сервисов), списки пакетов, базы. Для восстановления на «голое железо» — `/boot`, конфигурацию загрузчика. Проверка архива (`tar -tzf`) выявляет повреждения.

**Практическая работа №2: Резервное копирование с rsync**

**Задание:**
1. Создайте полную копию каталога через rsync.
2. Выполните инкрементное копирование.
3. Синхронизируйте удаления.
4. Исключите ненужные файлы.
5. Объясните преимущество rsync.

**Решение и пояснения:**
```bash
rsync -aAXv /home/ /backup/home/               # 1. Полная копия
rsync -aAXv /home/ /backup/home/               # 2. Инкрементально (только изменения)
rsync -aAXv --delete /home/ /backup/home/      # 3. Синхронизация удалений
rsync -aAXv --exclude='*.tmp' /home/ /backup/home/   # 4. Исключения
```
**Пояснения:**
rsync копирует только изменившиеся файлы и сохраняет атрибуты (`-a`), ACL/xattr (`-A`, `-X`). `--delete` удаляет в приёмнике то, чего нет в источнике. Эффективен для больших и регулярных бэкапов.

**Практическая работа №3: Работа с лентами и образами (dd)**

**Задание:**
1. Создайте образ раздела через `dd`.
2. Восстановите образ (в loop-устройство).
3. Посмотрите устройства лент.
4. Проверьте статус ленточного устройства.
5. Объясните преимущества и недостатки лент и дисков.

**Решение и пояснения:**
```bash
sudo dd if=/dev/sdb1 of=/backup/part.img bs=4M status=progress   # 1. Образ
sudo dd if=/backup/part.img of=/dev/loop0 bs=4M                   # 2. Восстановление
ls /dev/st* /dev/nst* 2>/dev/null                                 # 3. Ленточные устройства
mt -f /dev/st0 status                                             # 4. Статус
```
**Пояснения:**
`dd` делает побайтовую копию (образ раздела/диска). `/dev/st0` — лента с перемоткой, `/dev/nst0` — без. Ленты дёшевы для больших объёмов, но медленны и последовательны; диски быстрее и удобнее для инкрементов.

**Практическая работа №4: Автоматизация бэкапа и проверка**

**Задание:**
1. Напишите скрипт ежедневного бэкапа.
2. Добавьте ротацию (хранить 7 дней).
3. Запустите по cron.
4. Проверьте журнал выполнения.
5. Перечислите сетевые решения бэкапа.

**Решение и пояснения:**
```bash
#!/bin/bash
D=/backup; S=/etc; F=$D/etc_$(date +%F).tar.gz
tar -czf "$F" "$S" && find "$D" -name 'etc_*.tar.gz' -mtime +7 -delete
# cron: 0 2 * * * /usr/local/bin/backup.sh
```
**Пояснения:**
Скрипт создаёт датированный архив и удаляет старые. Cron запускает его ночью. Сетевые решения: Amanda, Bacula, Bareos, BackupPC. Важно регулярно тестировать восстановление, а не только создание бэкапа.
