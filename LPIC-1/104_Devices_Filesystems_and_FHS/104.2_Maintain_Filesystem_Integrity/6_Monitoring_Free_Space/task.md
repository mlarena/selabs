**Практическая работа №1: Базовый мониторинг дискового пространства**

**Задание:**      
1. Покажите общее использование дисков по всем подключенным файловым системам.      
2. Выведите информацию о дисках в удобочитаемом формате (человекочитаемые единицы).      
3. Покажите использование диска только для корневого раздела (`/`).      
4. Определите точку монтирования с наименьшим свободным местом.      
5. Проверьте использование inodes на всех файловых системах.      
6. Отслеживайте использование диска в реальном времени.      

**Решение и пояснения:**
```bash
df                             # 1. Статус всех файловых систем
df -h                          # 2. -h: human-readable (GB, MB)
df -h /                        # 3. Только корневой раздел
df -h | sort -k4 -n | head -2  # 4. Сортировка по свободному месту (4-й столбец)
df -i                          # 5. Использование inodes
watch -n 5 'df -h'             # 6. Обновление каждые 5 секунд
```

**Пояснения:** 
`df` (disk free) показывает свободное место.       
`-h` конвертирует байты в GB/MB.       
`df /` фильтрует по точке монтирования.       
`sort -k4 -n` сортирует численно по 4-му столбцу (свободное место).       
`df -i` показывает inodes (ограничение на количество файлов).       
`watch` обновляет команду периодически.

**Практическая работа №2: Анализ использования пространства директориями**

**Задание:**      
1. Определите размер домашнего каталога в удобочитаемом виде.      
2. Найдите 5 самых больших поддиректорий в `/var/log`.      
3. Отсортируйте вывод по размеру (от большего к меньшему).      
4. Покажите суммарный размер всех файлов с расширением `.log` в текущей директории.      
5. Определите, какие типы файлов занимают больше всего места.      
6. Проанализируйте использование пространства с визуальной индикацией.      

**Решение и пояснения:**
```bash
du -sh ~                        # 1. Размер домашнего каталога
du -h /var/log/* | sort -hr | head -5  # 2,3. Топ-5 с сортировкой
du -ch *.log                    # 4. -c показывает итог, -h человекочитаемо
find . -type f | xargs file | cut -d: -f2 | sort | uniq -c | sort -nr  # 5. Типы файлов
ncdu /var/log                   # 6. Интерактивный анализ (установить: apt install ncdu)
```
**Пояснения:** 
`du` (disk usage) показывает использование пространства.       
`-s` — суммарно,       
`-h` — human-readable.             
`sort -hr` сортирует по человекочитаемым числам в обратном порядке.       
`find + file + uniq` анализирует типы файлов.       
`ncdu` — мощный инструмент для визуального анализа.

**Практическая работа №3: Автоматизация проверки свободного места**

**Задание:**      
1. Напишите скрипт, который проверяет свободное место на корневом разделе.      
2. Если свободно менее 10%, выводите предупреждение.      
3. Добавьте проверку inodes (если свободно менее 5%).      
4. Скрипт должен показывать текущую дату и использование в %.      
5. Найдите файлы больше 100MB в домашнем каталоге.      
6. Настройте регулярный запуск скрипта по cron (раз в день).      

**Решение и пояснения:**
```bash
#!/bin/bash
# check_disk.sh
USE=$(df / | awk 'NR==2 {print $5}' | sed 's/%//')  # 1. Использование в %
INODES=$(df -i / | awk 'NR==2 {print $5}' | sed 's/%//')
echo "$(date): Использование диска: $USE%, inodes: $INODES%"  # 4

if [ $USE -gt 90 ]; then          # 2. >90% использовано
  echo "ВНИМАНИЕ: Свободно менее 10%!"
fi

if [ $INODES -gt 95 ]; then       # 3. >95% inodes использовано
  echo "ВНИМАНИЕ: Мало свободных inodes!"
fi

find ~ -type f -size +100M 2>/dev/null  # 5. Файлы >100MB
```
**Пояснения:** `df / | awk 'NR==2'` берет вторую строку (первая — заголовок). `sed 's/%//'` удаляет знак %. `-gt` значит "greater than". `find -size +100M` ищет файлы больше 100MB. Для cron: `crontab -e` → `0 9 * * * /path/to/check_disk.sh`

**Практическая работа №4: Очистка и оптимизация дискового пространства**      

**Задание:**      
1. Найдите и удалите все файлы с расширением `.tmp` старше 7 дней.      
2. Очистите кэш пакетов apt (устаревшие deb-файлы).      
3. Найдите и удалите пустые директории в `/tmp`.      
4. Очистите логи, которые весят больше 100MB.      
5. Покажите размер директорий перед и после очистки.      
6. Создайте отчет об освобожденном месте.      

**Решение и пояснения:**
```bash
find / -name "*.tmp" -mtime +7 -delete 2>/dev/null  # 1. Удаление старых .tmp
sudo apt clean                                     # 2. Очистка кэша apt
find /tmp -type d -empty -delete                   # 3. Удаление пустых директорий
find /var/log -size +100M -exec truncate -s 0 {} \; # 4. Очистка больших логов
du -sh /var/log /tmp                               # 5. Размер до очистки
echo "Освобождено: $(df -h / | awk 'NR==2 {print $4}')"  # 6. Отчет
```
**Пояснения:**      
`find -mtime +7` ищет файлы, измененные более 7 дней назад.       
`apt clean` удаляет загруженные deb-файлы.       
`find -empty -delete` удаляет пустые директории.       
`truncate -s 0` обнуляет файл (альтернатива: `> file.log`).             
`2>/dev/null` скрывает ошибки доступа.
