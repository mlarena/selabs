**Практическая работа №1: Локаль и язык системы**

**Задание:**
1. Выведите текущие настройки локали.
2. Посмотрите список доступных локалей.
3. Сгенерируйте локаль `ru_RU.UTF-8`.
4. Установите локаль по умолчанию.
5. Объясните переменные `LANG`, `LC_ALL`, `LC_*`.

**Решение и пояснения:**
```bash
locale                          # 1. Текущие настройки
locale -a | head                # 2. Доступные локали
sudo locale-gen ru_RU.UTF-8     # 3. Генерация
sudo update-locale LANG=ru_RU.UTF-8   # 4. Локаль по умолчанию
```
**Пояснения:**
`LANG` задаёт локаль по умолчанию. `LC_ALL` переопределяет все категории `LC_*` (время, числа, валюта). `LC_MESSAGES` отвечает за язык сообщений. Изменения локали применяются в новых сессиях.

**Практическая работа №2: Часовой пояс и время**

**Задание:**
1. Выведите текущий часовой пояс.
2. Посмотрите доступные часовые пояса.
3. Установите часовой пояс `Europe/Moscow`.
4. Проверьте время и аппаратные часы.
5. Объясните файлы `/etc/timezone` и `/etc/localtime`.

**Решение и пояснения:**
```bash
timedatectl                     # 1. Текущее состояние
timedatectl list-timezones | grep Europe   # 2. Список
sudo timedatectl set-timezone Europe/Moscow  # 3
date                            # 4. Системное время
hwclock --show                  # 4. Аппаратные часы
cat /etc/timezone               # 5. Текстовый часовой пояс
readlink -f /etc/localtime      # 5. Ссылка на zoneinfo
```
**Пояснения:**
`/etc/timezone` содержит имя пояса, `/etc/localtime` — символьная ссылка на файл из `/usr/share/zoneinfo/`. `timedatectl` управляет временем, часовым поясом и синхронизацией. `hwclock` работает с аппаратными часами.

**Практическая работа №3: Кодировки и iconv**

**Задание:**
1. Определите кодировку текстового файла.
2. Создайте файл в кодировке ISO-8859-1.
3. Преобразуйте его в UTF-8.
4. Проверьте результат.
5. Объясните разницу между ASCII, ISO-8859 и Unicode.

**Решение и пояснения:**
```bash
file -i text.txt                       # 1. Кодировка файла
iconv -f UTF-8 -t ISO-8859-1 text.txt -o latin.txt   # 2
iconv -f ISO-8859-1 -t UTF-8 latin.txt -o utf8.txt   # 3
file -i utf8.txt                       # 4. Проверка
```
**Пояснения:**
ASCII — 7-битная кодировка только для латиницы. ISO-8859 — 8-битные расширения (например, ISO-8859-1 для западноевропейских языков). Unicode (UTF-8) покрывает все языки и совместим с ASCII. `iconv` конвертирует между кодировками.

**Практическая работа №4: LANG=C и сортировка**

**Задание:**
1. Отсортируйте список строк с текущей локалью.
2. Сделайте то же с `LANG=C`.
3. Сравните порядок сортировки.
4. Используйте `LANG=C` в скрипте для стабильного вывода.
5. Объясните, почему `LANG=C` важен при скриптинге.

**Решение и пояснения:**
```bash
printf 'apple\nBanana\ncherry\n' | sort        # 1. С локалью
printf 'apple\nBanana\ncherry\n' | sort        # 2. LANG=C sort
LANG=C printf 'apple\nBanana\ncherry\n' | sort # 2. Байтовая сортировка
LC_ALL=C sort file.txt                          # 3. Сравнение
```
**Пояснения:**
`LANG=C` (или `LC_ALL=C`) отключает локализацию: сортировка идёт по байтам, сообщения — на английском. Это делает вывод скриптов предсказуемым и не зависящим от локали пользователя, что критично для разбора вывода программами.
