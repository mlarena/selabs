**Практическая работа №1: Базовая загрузка системы (uptime, load average)**

**Задание:**    
1. Определите, как долго работает система.    
2. Проверьте среднюю загрузку системы за 1, 5 и 15 минут.        
3. Рассчитайте количество ядер процессора.     
4. Определите, является ли загрузка высокой (сравните с количеством ядер).        
5. Отслеживайте загрузку системы в реальном времени.    
6. Создайте алиас `load` для быстрой проверки загрузки.     

**Решение и пояснения:**
```bash
uptime                          # 1. Время работы + load average
cat /proc/loadavg               # 2. Альтернативный способ (только load average)
nproc                           # 3. Количество ядер процессора
uptime | awk -F, '{print $3}'   # 4. Load average за 15 минут
# Сравнение: если load average > nproc * 0.7 — высокая загрузка
watch -n 2 'uptime'             # 5. Мониторинг каждые 2 секунды
alias load='uptime; echo "Ядер: $(nproc)"'  # 6. Алиас
```
**Пояснения:**     
Load average показывает среднее количество процессов в очереди на выполнение.     
Значения за 1, 5, 15 минут.     
Идеально, когда load average ≤ количеству ядер.     
`nproc` показывает доступные ядра.     
`watch` обновляет команду периодически.

**Практическая работа №2: Анализ использования CPU**

**Задание:**    
1. Покажите общую статистику использования CPU.    
2. Определите, какие процессы используют больше всего CPU.    
3. Проверьте тип процессора и его частоту.    
4. Мониторьте использование CPU в реальном времени.    
5. Найдите процессы с аномально высоким использованием CPU (>80%).    
6. Определите время работы самого долгого процесса.    

**Решение и пояснения:**    
```bash
mpstat 1 3                      # 1. Статистика CPU (каждую сек, 3 раза)
ps aux --sort=-%cpu | head -10  # 2. Топ-10 процессов по CPU
lscpu | grep -E "(Model name|MHz)"  # 3. Информация о процессоре
top -b -n 1 | grep "^%Cpu"      # 4. Быстрая проверка загрузки CPU
ps aux | awk '$3 > 80 {print $0}'  # 5. Процессы с >80% CPU
ps -eo pid,etime,cmd | sort -k2 -r | head -5  # 6. Самые долгие процессы
```

**Пояснения:**     
`mpstat` показывает детальную статистику по CPU.     
`%Cpu(s)` в top: us — пользователь, sy — система, id — простой.     
`ps -eo etime` показывает время выполнения процесса.     
`lscpu` выводит информацию о архитектуре CPU.

**Практическая работа №3: Мониторинг ввода-вывода (I/O)**

**Задание:**    
1. Установите утилиту для мониторинга I/O (`iotop`).    
2. Покажите процессы, активно использующие дисковый ввод-вывод.    
3. Определите, какой диск наиболее загружен.    
4. Проверьте статистику чтения/записи для всех дисков.    
5. Найдите процессы с высокой дисковой активностью.    
6. Отслеживайте I/O в реальном времени.    

**Решение и пояснения:**    
```bash
sudo apt install iotop -y       # 1. Установка iotop
sudo iotop -o                   # 2. Активные процессы I/O (q для выхода)
iostat -x 1 3                   # 3. Статистика дисков (%util — загрузка)
iostat -d                      # 4. Базовая статистика чтения/записи
sudo iotop -b -n 3 | head -20   # 5. Снимок процессов I/O
watch -n 1 'iostat -x 1 1'      # 6. Мониторинг каждую секунду
```
**Пояснения:**     
`iotop` аналогичен `top`, но для I/O.     
`-o` показывает только активные процессы.     
`iostat -x` показывает расширенную статистику:     
`%util` — процент загрузки диска (близко к 100% — проблема).         
`await` — среднее время ожидания I/O.

**Практическая работа №4: Создание скрипта мониторинга**

**Задание:**    
1. Напишите скрипт, который собирает ключевые метрики системы.    
2. Включите: загрузку CPU, использование памяти, load average.    
3. Добавьте проверку дискового пространства.    
4. Если какая-либо метрика превышает порог, выводите предупреждение.    
5. Сохраняйте отчет в файл с временной меткой.    
6. Настройте запуск скрипта каждые 10 минут через cron.    

**Решение и пояснения:**
```bash
#!/bin/bash
# monitor.sh
LOG="/var/log/system_monitor_$(date +%Y%m%d).log"

echo "=== $(date) ===" >> $LOG
echo "Load: $(uptime | awk -F: '{print $NF}')" >> $LOG
echo "CPU: $(top -bn1 | grep '%Cpu' | cut -c 9-)" >> $LOG
echo "Memory: $(free -h | grep Mem | awk '{print $3"/"$2}')" >> $LOG
echo "Disk: $(df -h / | awk 'NR==2 {print $5}')" >> $LOG

# Проверка порогов
LOAD=$(uptime | awk -F, '{print $3}' | sed 's/ //g')
if [ $(echo "$LOAD > 2.0" | bc) -eq 1 ]; then
  echo "ВНИМАНИЕ: Высокая загрузка: $LOAD" >> $LOG
fi
```    

**Пояснения:**     
Скрипт собирает ключевые метрики.     
`bc` используется для сравнения чисел с плавающей точкой.     
Пороги: load average > 2.0, память > 90%, диск > 85%.     
Cron: `*/10 * * * * /path/to/monitor.sh`.     
Логи помогают анализировать историю проблем.
