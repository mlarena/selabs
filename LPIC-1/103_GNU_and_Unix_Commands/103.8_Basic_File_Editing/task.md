**Практическая работа №1: Основы vi**

**Задание:**
1. Откройте новый файл `vi_test.txt` в редакторе `vi`.
2. Войдите в режим вставки и введите три строки текста.
3. Сохраните файл и выйдите.
4. Откройте файл и перейдите к последней строке.
5. Удалите одну строку и сохраните изменения.

**Решение и пояснения:**
```text
vi vi_test.txt      # открыть файл
i                   # режим вставки, ввести текст
Esc                 # возврат в командный режим
:wq                 # сохранить и выйти
vi vi_test.txt      # открыть снова
G                   # перейти к последней строке
dd                  # удалить строку
:wq                 # сохранить
```
**Пояснения:**
`vi` имеет режимы: командный (по умолчанию) и вставки. `i` — вставка перед курсором, `Esc` — выход в командный режим. `:w` сохранить, `:q` выйти, `:wq` сохранить и выйти, `:q!` выйти без сохранения. `dd` удаляет строку.

**Практическая работа №2: Навигация и поиск в vi**

**Задание:**
1. Откройте файл `/etc/services` в vi (только чтение).
2. Перейдите в начало и конец файла.
3. Найдите слово `ssh`.
4. Перейдите к следующему совпадению.
5. Выйдите без изменений.

**Решение и пояснения:**
```text
view /etc/services   # открыть в режиме только чтения
gg                   # в начало файла
G                    # в конец файла
/ssh                 # поиск вперёд
n                    # следующее совпадение
:q!                  # выйти без сохранения
```
**Пояснения:**
`gg` — начало, `G` — конец файла, `:n` — переход к строке n. Поиск вперёд — `/шаблон`, назад — `?шаблон`, повтор — `n`. `view` открывает файл в режиме только чтения.

**Практическая работа №3: Редактирование, копирование, вставка**

**Задание:**
1. Откройте файл и скопируйте строку.
2. Вставьте её ниже.
3. Отмените последнее действие.
4. Замените слово во всём файле.
5. Сохраните под новым именем.

**Решение и пояснения:**
```text
yy                   # скопировать (yank) строку
p                    # вставить ниже курсора
u                    # отменить последнее действие
:%s/old/new/g        # заменить во всём файле
:w newfile.txt       # сохранить под новым именем
```
**Пояснения:**
`yy` копирует строку, `dd` вырезает, `p` вставляет. `u` — отмена, `Ctrl+r` — повтор. Подстановка `:%s/old/new/g` заменяет `old` на `new` во всех строках (`%` — весь файл, `g` — все вхождения).

**Практическая работа №4: Настройка редактора по умолчанию**

**Задание:**
1. Проверьте текущий редактор по умолчанию.
2. Установите `nano` как редактор по умолчанию.
3. Откройте файл через `nano`.
4. Настройте редактор по умолчанию в `~/.bashrc`.
5. Объясните переменные `EDITOR` и `VISUAL`.

**Решение и пояснения:**
```bash
echo $EDITOR                       # 1. Текущий редактор
export EDITOR=nano                 # 2. Установка на сессию
echo 'export EDITOR=nano' >> ~/.bashrc   # 4. Постоянно
nano test.txt                      # 3. Открытие в nano
sudo update-alternatives --config editor  # Системный редактор
```
**Пояснения:**
`EDITOR` задаёт редактор для консольных программ, `VISUAL` — для полноэкранных. `update-alternatives --config editor` меняет системный редактор (`/usr/bin/editor`). Настройка в `~/.bashrc` действует для всех новых сессий пользователя.
