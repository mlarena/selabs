**Практическая работа №2: Доступ к общим ресурсам и печати**

**Задание:**
1. Подключитесь к CIFS-ресурсу из Windows.
2. Подключите сетевой принтер.
3. Настройте постоянное подключение диска.
4. Проверьте права доступа.
5. Объясните разницу сопоставленного диска и UNC-пути.

**Решение / Описание:**
```text
# UNC-путь: \\server\docs
# Сопоставить диск: net use Z: \\server\docs /persistent:yes
# Принтер: net use LPT1: \\server\printer
# Проверка прав: icacls \\server\docs\file.txt
```
**Пояснения:**
Windows обращается к ресурсам по UNC (`\\server\share`) или сопоставляет букву диска. `net use` подключает ресурсы и принтеры. Права определяются ACL ресурса и членством в группах AD.

**Практическая работа №3: GPO и сценарии входа**

**Задание:**
1. Посмотрите GPO в Samba AD.
2. Создайте GPO (через Windows RSAT или `samba-tool gpo`).
3. Настройте сценарий входа.
4. Привяжите GPO к OU.
5. Проверьте применение на клиенте.

**Решение и пояснения:**
```bash
sudo samba-tool gpo listall
sudo samba-tool gpo create "LoginScripts"
sudo samba-tool gpo setlink "CN=Users,DC=lab,DC=local" <GUID>
# На Windows: gpupdate /force
# smb.conf: logon script = login.bat
```
**Пояснения:**
GPO централизованно управляют настройками Windows. Samba AD поддерживает GPO через SYSVOL и `samba-tool gpo`. Сценарии входа (`logon script`) задаются в GPO или `smb.conf`. Применение проверяют `gpupdate`.

**Практическая работа №4: Профили и перенаправление папок**

**Задание:**
1. Настройте перемещаемый профиль.
2. Настройте перенаправление папок.
3. Проверьте создание профиля.
4. Удалённый доступ к рабочему столу (`rdesktop`).
5. Объясните плюсы и минусы перемещаемых профилей.

**Решение / Описание:**
```text
# smb.conf: logon path = \\%L\profiles\%U
# logon home = \\%L\%U
# GPO: перенаправление Documents на \\server\users\%username%
# Удалённый рабочий стол: rdesktop windows-host
```
**Пояснения:**
Перемещаемые профили хранятся на сервере и доступны с любой машины, но замедляют вход и увеличивают нагрузку. Перенаправление папок переносит только данные. `rdesktop`/RDP даёт удалённый доступ к рабочему столу Windows.
