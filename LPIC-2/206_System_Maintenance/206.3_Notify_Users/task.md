**Практическая работа №1: Сообщения при входе**

**Задание:**
1. Посмотрите файл `/etc/issue`.
2. Посмотрите `/etc/issue.net`.
3. Измените приветствие `/etc/motd`.
4. Проверьте отображение при входе.
5. Объясните разницу issue и motd.

**Решение и пояснения:**
```bash
cat /etc/issue                              # 1. До входа (локально)
cat /etc/issue.net                          # 2. До входа (по сети)
echo "Добро пожаловать в учебный стенд" | sudo tee /etc/motd   # 3
cat /etc/motd                               # 4. После входа
```
**Пояснения:**
`/etc/issue` показывается до входа в систему (локально), `/etc/issue.net` — при удалённом входе (например, SSH с `Banner`). `/etc/motd` (message of the day) выводится после успешного входа.

**Практическая работа №2: Уведомление активных пользователей**

**Задание:**
1. Посмотрите список активных пользователей.
2. Отправьте сообщение через `wall`.
3. Узнайте, кто сейчас в системе.
4. Отправьте сообщение конкретному пользователю.
5. Объясните, когда используют wall.

**Решение и пояснения:**
```bash
who                                        # 1. Кто в системе
echo "Плановое обслуживание через 10 мин" | wall   # 2. Всем
w                                          # 3. Активные и их нагрузка
write user pts/0                           # 4. Конкретному пользователю
```
**Пояснения:**
`wall` рассылает сообщение всем вошедшим пользователям (важно перед перезагрузкой или обслуживанием). `write` пишет конкретному пользователю. `who`/`w` показывают активные сессии.

**Практическая работа №3: Плановое выключение с уведомлением**

**Задание:**
1. Запланируйте перезагрузку через 10 минут.
2. Отмените запланированную перезагрузку.
3. Выполните выключение с сообщением.
4. Посмотрите запланированные задачи shutdown.
5. Объясните, зачем уведомлять пользователей.

**Решение и пояснения:**
```bash
sudo shutdown -r +10 "Перезагрузка через 10 минут"   # 1. Через 10 мин
sudo shutdown -c                                      # 2. Отмена
sudo shutdown -h now "Система выключается"            # 3. Немедленно
```
**Пояснения:**
`shutdown` уведомляет всех пользователей через `wall` и корректно завершает процессы. `+10` — через 10 минут, `now` — сейчас, `-c` — отмена. Заблаговременное уведомление предотвращает потерю данных.

**Практическая работа №4: Управление сообщениями через systemd**

**Задание:**
1. Узнайте, как systemd выводит motd.
2. Проверьте генераторы motd.
3. Создайте динамический motd-скрипт.
4. Проверьте результат.
5. Объясните разницу статического и динамического motd.

**Решение и пояснения:**
```bash
ls /etc/update-motd.d/                     # 1-2. Скрипты motd
sudo tee /etc/update-motd.d/99-custom >/dev/null <<'EOF'
#!/bin/sh
echo "Загрузка: $(uptime -p)"
EOF
sudo chmod +x /etc/update-motd.d/99-custom
run-parts /etc/update-motd.d/              # 4. Проверка
```
**Пояснения:**
systemd через `pam_motd` собирает `/etc/motd` из скриптов `/etc/update-motd.d/` и `/run/motd.d/`. Динамический motd показывает актуальную информацию (загрузка, обновления) вместо статического текста.
