**Практическая работа №1: Установка и настройка vsftpd**

**Задание:**
1. Установите `vsftpd`.
2. Настройте анонимный доступ на чтение.
3. Настройте локальных пользователей.
4. Запустите службу.
5. Проверьте подключение через FTP-клиент.

**Решение и пояснения:**
```bash
sudo apt install -y vsftpd ftp
# /etc/vsftpd.conf:
# anonymous_enable=YES
# local_enable=YES
# write_enable=NO
sudo systemctl enable --now vsftpd
ftp localhost                            # 5. Проверка (anonymous)
```
**Пояснения:**
vsftpd — безопасный FTP-сервер. `anonymous_enable` разрешает анонимный доступ, `local_enable` — локальных пользователей, `write_enable` — запись. Конфигурация в `/etc/vsftpd.conf`.

**Практическая работа №2: Анонимная загрузка (осторожно)**

**Задание:**
1. Разрешите анонимную загрузку файлов.
2. Ограничьте права на запись.
3. Настройте отдельный каталог для загрузок.
4. Проверьте загрузку файла.
5. Объясните риски анонимной записи.

**Решение и пояснения:**
```bash
# /etc/vsftpd.conf:
# write_enable=YES
# anon_upload_enable=YES
# anon_mkdir_write_enable=YES
# anon_root=/srv/ftp
sudo mkdir -p /srv/ftp/upload && sudo chown ftp:ftp /srv/ftp/upload
sudo systemctl restart vsftpd
```
**Пояснения:**
Анонимная запись опасна: возможна загрузка вредоносных файлов и заполнение диска. Меры: отдельный каталог, ограничение прав, квоты, запрет исполнения. В продакшене предпочитают SFTP/FTPS.

**Практическая работа №3: Пассивный режим и firewall**

**Задание:**
1. Включите пассивный режим.
2. Задайте диапазон пассивных портов.
3. Откройте порты в firewall.
4. Настройте внешний IP для PASV.
5. Объясните разницу активного и пассивного режима.

**Решение и пояснения:**
```bash
# /etc/vsftpd.conf:
# pasv_enable=YES
# pasv_min_port=40000
# pasv_max_port=40100
# pasv_address=<external_ip>
sudo iptables -A INPUT -p tcp --dport 40000:40100 -j ACCEPT
sudo systemctl restart vsftpd
```
**Пояснения:**
В активном режиме сервер сам подключается к клиенту (проблемы с NAT/firewall). В пассивном — клиент подключается к серверу, поэтому нужен диапазон открытых портов. Пассивный режим предпочтителен за NAT.

**Практическая работа №4: Диагностика и альтернативы**

**Задание:**
1. Посмотрите журнал vsftpd.
2. Проверьте статус службы.
3. Проверьте доступность портов.
4. Сравните vsftpd, Pure-FTPd, ProFTPd.
5. Объясните, почему FTP устаревает.

**Решение и пояснения:**
```bash
sudo journalctl -u vsftpd | tail
ss -tlnp | grep :21
ftp -p localhost                         # Пассивный режим
```
**Пояснения:**
FTP передаёт данные и пароли открытым текстом, поэтому устаревает в пользу SFTP (SSH) и FTPS. Pure-FTPd и ProFTPd — альтернативы vsftpd с иными наборами функций. Диагностика — журналы и проверка портов 21 и пассивного диапазона.
