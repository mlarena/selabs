**Практическая работа №1: Основы CUPS**

**Задание:**
1. Установите CUPS.
2. Запустите и включите службу `cups`.
3. Откройте веб-интерфейс CUPS.
4. Посмотрите список принтеров.
5. Объясните архитектуру CUPS.

**Решение и пояснения:**
```bash
sudo apt install -y cups                 # 1. Установка
sudo systemctl enable --now cups         # 2. Запуск
# Веб-интерфейс: http://localhost:631    # 3
lpstat -p -d                             # 4. Принтеры и принтер по умолчанию
```
**Пояснения:**
CUPS — система печати Linux. Демон `cupsd` слушает порт 631 и предоставляет веб-интерфейс. Конфигурация — в `/etc/cups/`. Принтеры описываются в `printers.conf`, классы — в `classes.conf`.

**Практическая работа №2: Добавление и настройка принтера**

**Задание:**
1. Добавьте виртуальный PDF-принтер.
2. Проверьте его в списке.
3. Назначьте принтер по умолчанию.
4. Выведите параметры принтера.
5. Объясните разницу между локальным и сетевым принтером.

**Решение и пояснения:**
```bash
sudo apt install -y cups-pdf             # 1. PDF-принтер
sudo lpadmin -p PDF -v /usr/lib/cups/backend/cups-pdf -m everywhere
lpstat -p PDF                            # 2. Проверка
sudo lpadmin -d PDF                      # 3. Принтер по умолчанию
lpoptions -p PDF                         # 4. Параметры
```
**Пояснения:**
`lpadmin` добавляет принтер (`-p` имя, `-v` устройство, `-m` драйвер). `cups-pdf` печатает в PDF-файлы (обычно в `~/PDF`). Локальный принтер подключён напрямую, сетевой доступен по IPP/Socket/LPD.

**Практическая работа №3: Управление заданиями печати**

**Задание:**
1. Отправьте файл на печать.
2. Посмотрите очередь печати.
3. Приостановите очередь принтера.
4. Возобновите печать.
5. Удалите задание из очереди.

**Решение и пояснения:**
```bash
echo "test print" > /tmp/print.txt
lp -d PDF /tmp/print.txt                 # 1. Отправка на печать
lpq -P PDF                               # 2. Очередь
cupsdisable PDF                          # 3. Пауза
cupsenable PDF                           # 4. Возобновление
lprm -P PDF 1                            # 5. Удаление задания №1
```
**Пояснения:**
`lp`/`lpr` отправляют файл на печать, `lpq` показывает очередь, `lprm`/`cancel` удаляют задания. `cupsdisable`/`cupsenable` приостанавливают и возобновляют очередь принтера. Это базовые операции управления печатью.

**Практическая работа №4: Диагностика печати**

**Задание:**
1. Просмотрите журнал CUPS.
2. Проверьте состояние службы `cups`.
3. Посмотрите ошибки печати.
4. Перезапустите службу.
5. Объясните типовые причины проблем с печатью.

**Решение и пояснения:**
```bash
sudo journalctl -u cups -n 50            # 1. Журнал
systemctl status cups                    # 2. Состояние
sudo tail -f /var/log/cups/error_log     # 3. Ошибки
sudo systemctl restart cups              # 4. Перезапуск
```
**Пояснения:**
Журналы CUPS — в `/var/log/cups/error_log`, `access_log`, `page_log`. Типовые проблемы: неверный драйвер, недоступность сетевого принтера, занятый порт 631, права доступа. Перезапуск службы применяет изменения конфигурации.
