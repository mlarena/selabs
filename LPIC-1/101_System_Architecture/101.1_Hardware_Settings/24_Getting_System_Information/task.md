**Практическая работа №1: Базовая информация о системе**     

**Задание:**     
1. Определите версию дистрибутива и кодовое имя.     
2. Узнайте версию ядра Linux.     
3. Проверьте архитектуру процессора.     
4. Определите время работы системы (uptime).     
5. Узнайте имя хоста и домена.     
6. Получите информацию о сборке ядра.     

**Решение и пояснения:**
```bash
cat /etc/os-release                    # 1. Версия дистрибутива и кодовое имя
uname -r                               # 2. Версия ядра
uname -m                               # 3. Архитектура (x86_64, arm и т.д.)
uptime                                 # 4. Время работы и нагрузка
hostname && hostname -d                # 5. Имя хоста и домен
cat /proc/version                      # 6. Подробная информация о сборке ядра
```
**Пояснения:**      
`/etc/os-release` содержит информацию о дистрибутиве.      
`uname -r` показывает версию ядра.      
`uptime` дополнительно показывает среднюю нагрузку за 1, 5 и 15 минут.      
`hostname -d` может не показывать домен, если он не настроен.

**Практическая работа №2: Информация о железе**     

**Задание:**     
1. Определите модель процессора и количество ядер.     
2. Узнайте общий объем оперативной памяти.     
3. Найдите информацию о материнской плате (BIOS/UEFI).     
4. Получите список подключенных USB-устройств.     
5. Узнайте температуру процессора (если поддерживается).     
6. Проверьте информацию о батарее (для ноутбуков).     

**Решение и пояснения:**     
```bash
lscpu | grep -E "(Model name|CPU\(s\):)"  # 1. Модель и количество ядер
free -h | grep Mem | awk '{print $2}'      # 2. Объем RAM
sudo dmidecode -t bios | grep -E "(Vendor|Version)"  # 3. Информация о BIOS
lsusb                                       # 4. Список USB-устройств
sensors 2>/dev/null | grep -i temp | head -3 # 5. Температура (требует пакета lm-sensors)
upower -i $(upower -e | grep battery) | grep -E "(capacity|state)"  # 6. Батарея
```
**Пояснения:**      
`lscpu` показывает детальную информацию о процессоре.      
`dmidecode` требует root прав для доступа к информации о железе.      
`sensors` может потребовать настройки (`sensors-detect`).      
`upower` показывает информацию об источниках питания.

**Практическая работа №3: Сетевые настройки и интерфейсы**     

**Задание:**     
1. Определите IP-адреса всех сетевых интерфейсов.     
2. Узнайте MAC-адреса интерфейсов.     
3. Проверьте таблицу маршрутизации.     
4. Узнайте DNS-сервера системы.     
5. Определите публичный IP-адрес (внешний).     
6. Проверьте открытые сетевые порты.     

**Решение и пояснения:**     
```bash
ip addr show                           # 1. IP-адреса интерфейсов
ip link show | grep ether              # 2. MAC-адреса
ip route                               # 3. Таблица маршрутизации
cat /etc/resolv.conf | grep nameserver # 4. DNS-сервера
curl -s ifconfig.me                    # 5. Внешний IP (требует интернета)
sudo ss -tuln                          # 6. Открытые порты
```
**Пояснения:**      
`ip` — современная замена устаревшим `ifconfig`,      
`route`. 
`ss` — замена `netstat`. 
`/etc/resolv.conf` содержит DNS настройки (может перезаписываться NetworkManager).      
Внешний IP можно получить разными сервисами (`ifconfig.co`, `icanhazip.com`).

**Практическая работа №4: Создание отчета о системе**     

**Задание:**     
1. Создайте скрипт, который собирает информацию о системе.     
2. Скрипт должен включать: дистрибутив, ядро, процессор, память, диски.     
3. Добавьте информацию о сетевых интерфейсах.     
4. Сохраняйте отчет в файл с датой и временем.     
5. Добавьте проверку свободного места на дисках.     
6. Настройте запуск скрипта ежедневно через cron.     

**Решение и пояснения:**     
```bash
#!/bin/bash
# system_report.sh
REPORT="/var/log/system_report_$(date +%Y%m%d_%H%M%S).log"

{
echo "=== System Report ==="
echo "Date: $(date)"
echo "Distro: $(cat /etc/os-release | grep PRETTY_NAME | cut -d= -f2)"
echo "Kernel: $(uname -r)"
echo "CPU: $(lscpu | grep 'Model name' | cut -d: -f2 | xargs)"
echo "Memory: $(free -h | grep Mem | awk '{print $2}') total"
echo "=== Disks ==="
df -h
echo "=== Network ==="
ip addr show | grep -E "(inet|^[0-9])" | grep -v "127.0.0.1"
} > $REPORT

# Проверка: cat $REPORT

# Для cron (запуск ежедневно в 3:00):
# crontab -e → 0 3 * * * /path/to/system_report.sh
```
**Пояснения:**      
Скрипт создает структурированный отчет.      
`xargs` убирает лишние пробелы.      
Фильтрация IP-адресов исключает localhost.      
Cron-задание выполняется от имени пользователя, убедитесь, что у пользователя есть права на запись в `/var/log/`.      
Такие отчеты полезны для мониторинга и аудита.
