# LPIC-3 Security

[Оглавление проекта](home.md)

Специализация LPIC-3 Security подтверждает навыки enterprise-безопасности Linux: криптография, PKI, защита хоста, мандатный доступ, сетевая безопасность, аудит и оценка уязвимостей.
Экзамен: **303-300**. Требуется действующий LPIC-2. Подробнее — [формат экзаменов](docs/exam-format.md).
