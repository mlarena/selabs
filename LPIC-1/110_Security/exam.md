# Экзаменационные боевые задачи — Тема 110: Security

Задачи приближены к реальным заданиям экзамена **102-500**.

## Задача 1. Администрирование безопасности: аудит портов

**Условие:** Найдите все открытые порты и определите, какие процессы их слушают; выявите подозрительные.

**Ожидаемый результат:** Список портов и процессов получен.

**Решение и пояснения:**
```bash
sudo ss -tulpn
sudo lsof -i -P -n | grep LISTEN
sudo nmap -sT localhost
sudo netstat -tulpn 2>/dev/null || echo "используйте ss"
```
`ss -tulpn` показывает слушающие сокеты и процессы. `lsof -i` — процессы с сетевыми соединениями. `nmap` — внешний взгляд на порты. Неожиданные порты — повод для расследования.

## Задача 2. Поиск процессов, использующих файлы

**Условие:** Определите, какой процесс держит удалённый, но занятый файл (например, лог).

**Ожидаемый результат:** Процесс найден.

**Решение и пояснения:**
```bash
sudo lsof +L1                    # Удалённые, но открытые файлы
sudo lsof /var/log/syslog
sudo fuser -v /var/log/syslog
sudo lsof | grep deleted
```
`lsof +L1` находит удалённые открытые файлы (частая причина «занятого» места). `fuser` показывает процессы, использующие файл. Перезапуск сервиса освобождает дескриптор.

## Задача 3. Настройка безопасности хоста

**Условие:** Ограничьте доступ к `su`, настройте политику паролей и лимиты для пользователей.

**Ожидаемый результат:** Меры безопасности применены.

**Решение и пояснения:**
```bash
# /etc/pam.d/su: auth required pam_wheel.so use_uid  (su только для wheel)
sudo usermod -aG wheel alice
# /etc/pam.d/common-password: pam_pwquality.so minlen=12
# /etc/security/limits.conf: @devs hard nproc 200
sudo faillock --user alice
```
`pam_wheel` ограничивает `su` группой wheel. `pam_pwquality` — сложность паролей. `limits.conf` — лимиты ресурсов. `pam_faillock` блокирует после неудач.

## Задача 4. Шифрование данных

**Условие:** Зашифруйте и расшифруйте файл симметрично, создайте и проверьте подпись.

**Ожидаемый результат:** Файл зашифрован, подпись проверена.

**Решение и пояснения:**
```bash
gpg --symmetric --cipher-algo AES256 secret.txt     # Шифрование
gpg --decrypt secret.txt.gpg > secret.out           # Расшифровка
gpg --detach-sign secret.txt                        # Подпись
gpg --verify secret.txt.sig secret.txt              # Проверка
sha256sum secret.txt                                # Контрольная сумма
```
`gpg` реализует симметричное шифрование и подписи. Хэш (`sha256sum`) проверяет целостность. Шифрование защищает данные, подпись подтверждает авторство и неизменность.

## Задача 5. SSH: ключи и ограничения

**Условие:** Настройте вход по SSH-ключам, отключите парольный вход, ограничьте пользователей.

**Ожидаемый результат:** Вход по ключу работает, пароль отключён.

**Решение и пояснения:**
```bash
ssh-keygen -t ed25519
ssh-copy-id user@server
# sshd_config: PubKeyAuthentication yes ; PasswordAuthentication no ; AllowUsers user
sudo sshd -t && sudo systemctl restart ssh
ssh user@server
```
Ключи (Ed25519/RSA) устойчивее паролей. Публичный ключ в `~/.ssh/authorized_keys`. `sshd -t` проверяет конфигурацию перед перезапуском, чтобы не потерять доступ.
