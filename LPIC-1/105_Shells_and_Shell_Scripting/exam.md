# Экзаменационные боевые задачи — Тема 105: Shells and Shell Scripting

Задачи приближены к реальным заданиям экзамена **102-500**.

## Задача 1. Настройка окружения оболочки

**Условие:** Создайте постоянный псевдоним `ll` для `ls -la`, задайте переменную `EDITOR=vim` и добавьте каталог в `PATH`.

**Ожидаемый результат:** Настройки применяются в новых сессиях.

**Решение и пояснения:**
```bash
echo "alias ll='ls -la'" >> ~/.bashrc
echo "export EDITOR=vim" >> ~/.bashrc
echo "export PATH=\$PATH:/opt/bin" >> ~/.bashrc
source ~/.bashrc
alias ll ; echo $EDITOR
```
`~/.bashrc` — для интерактивных оболочек, `~/.profile`/`~/.bash_profile` — для входа. `alias` — псевдонимы, `export` — переменные окружения. `source` применяет изменения.

## Задача 2. Простой скрипт с аргументами

**Условие:** Напишите скрипт, который принимает имя файла и выводит число строк и слов.

**Ожидаемый результат:** Скрипт работает с аргументами.

**Решение и пояснения:**
```bash
#!/bin/bash
if [ $# -ne 1 ]; then
    echo "Использование: $0 <файл>" >&2
    exit 1
fi
wc -l "$1" ; wc -w "$1"
```
`$#` — число аргументов, `$1` — первый аргумент, `$0` — имя скрипта. Проверка аргументов и `exit 1` при ошибке — хорошая практика. `#!/bin/bash` — shebang.

## Задача 3. Условные конструкции и циклы

**Условие:** Напишите скрипт, который перебирает аргументы и выводит, какие из них — существующие файлы.

**Ожидаемый результат:** Скрипт корректно различает файлы.

**Решение и пояснения:**
```bash
#!/bin/bash
for f in "$@"; do
    if [ -f "$f" ]; then
        echo "$f: файл"
    elif [ -d "$f" ]; then
        echo "$f: каталог"
    else
        echo "$f: не существует"
    fi
done
```
`for ... in "$@"` перебирает аргументы. Тесты: `-f` (файл), `-d` (каталог), `-e` (существует). Кавычки вокруг `"$f"` защищают пробелы в именах.

## Задача 4. Обработка кодов возврата

**Условие:** Скрипт должен проверить доступность хоста и вернуть код 0/1.

**Ожидаемый результат:** Код возврата соответствует результату.

**Решение и пояснения:**
```bash
#!/bin/bash
if ping -c1 -W2 "$1" >/dev/null 2>&1; then
    echo "$1 доступен"
    exit 0
else
    echo "$1 недоступен"
    exit 1
fi
```
`$?` хранит код возврата последней команды. `exit 0` — успех, `exit 1` — ошибка. Проверка через `if команда` использует код возврата напрямую.

## Задача 5. Функции и ввод данных

**Условие:** Напишите скрипт с функцией приветствия и чтением ввода от пользователя.

**Ожидаемый результат:** Скрипт принимает ввод и вызывает функцию.

**Решение и пояснения:**
```bash
#!/bin/bash
greet() { echo "Привет, $1!"; }
read -p "Ваше имя: " name
greet "$name"
# Обработка с таймаутом: read -t 10 -p "Ввод: " var
```
Функции объявляются `name() { ... }`, аргументы — `$1`. `read` читает ввод, `-p` задаёт приглашение, `-t` — таймаут.
