**Практическая работа №1: Основные окружения рабочего стола**

**Задание:**
1. Выведите список установленных окружений рабочего стола.
2. Определите, какое окружение активно сейчас.
3. Установите лёгкое окружение Xfce.
4. Установите оконный менеджер без окружения (например, openbox).
5. Объясните разницу между окружением и оконным менеджером.

**Решение и пояснения:**
```bash
ls /usr/share/xsessions/              # 1. Доступные сессии
echo $XDG_CURRENT_DESKTOP            # 2. Активное окружение
sudo apt install -y xfce4            # 3. Установка Xfce
sudo apt install -y openbox          # 4. Оконный менеджер
```
**Пояснения:**
Окружение рабочего стола (GNOME, KDE, Xfce) включает оконный менеджер, панель, файловый менеджер и набор приложений. Оконный менеджер (openbox, i3) управляет только окнами. Xfce — лёгкое окружение для слабых машин.

**Практическая работа №2: Протоколы удалённого рабочего стола**

**Задание:**
1. Установите сервер VNC (tigervnc).
2. Запустите VNC-сервер и задайте пароль.
3. Подключитесь к нему с другой машины.
4. Опишите протоколы RDP, VNC, SPICE, XDMCP.
5. Объясните, какой протокол выбрать для виртуальных машин.

**Решение и пояснения:**
```bash
sudo apt install -y tigervnc-standalone-server
vncpasswd                            # 2. Задать пароль
vncserver :1                         # 2. Запуск на дисплее :1
# Клиент: vncviewer host:5901        # 3. Подключение
```
**Пояснения:**
VNC — кроссплатформенный протокол удалённого доступа к экрану. RDP — протокол Microsoft, часто используется в Windows-инфраструктуре. SPICE оптимизирован для виртуальных машин (KVM/QEMU). XDMCP устарел и небезопасен.

**Практическая работа №3: XDMCP и защита**

**Задание:**
1. Проверьте, включён ли XDMCP в дисплейном менеджере.
2. Включите XDMCP (для учебного стенда).
3. Подключитесь к удалённому дисплею.
4. Выключите XDMCP обратно.
5. Объясните, почему XDMCP небезопасен.

**Решение и пояснения:**
```bash
grep -ri xdmcp /etc/lightdm/ 2>/dev/null    # 1. Настройка
# В /etc/lightdm/lightdm.conf:
# [XDMCPServer]
# enabled=true
sudo systemctl restart lightdm              # 2. Применение
# Клиент: X :1 -query server_ip            # 3. Подключение
```
**Пояснения:**
XDMCP позволяет получать экран входа по сети, но передаёт данные без шифрования, что делает его уязвимым к перехвату. Для учебного стенда включают временно; в продакшене используют SSH-туннели или RDP/SPICE.

**Практическая работа №4: Выбор окружения**

**Задание:**
1. Сравните потребление памяти GNOME и Xfce.
2. Определите установленный объём ОЗУ.
3. Установите лёгкий файловый менеджер.
4. Настройте автозапуск приложения в сессии.
5. Объясните критерии выбора окружения для сервера и рабочей станции.

**Решение и пояснения:**
```bash
free -h                              # 2. Объём ОЗУ
ps -o rss= -C gnome-shell 2>/dev/null | awk '{s+=$1} END {print s/1024 " MB"}'
sudo apt install -y pcmanfm          # 3. Лёгкий файловый менеджер
mkdir -p ~/.config/autostart         # 4. Автозапуск
cp /usr/share/applications/pcmanfm.desktop ~/.config/autostart/
```
**Пояснения:**
На серверах графическое окружение не нужно — достаточно консоли. На рабочих станциях выбирают окружение по объёму ОЗУ и задачам: Xfce/LXQt для слабых машин, GNOME/KDE для современных. Автозапуск настраивается через `~/.config/autostart/*.desktop`.
