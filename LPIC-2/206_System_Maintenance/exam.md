# Экзаменационные боевые задачи — Тема 206: System Maintenance

Задачи приближены к реальным заданиям экзамена **201-450**.

## Задача 1. Сборка программы из исходников

**Условие:** Скачайте, соберите и установите программу из исходников в `/usr/local`.

**Ожидаемый результат:** Программа установлена и работает.

**Решение и пояснения:**
```bash
sudo apt install -y build-essential
wget https://example.org/app-1.0.tar.gz
tar -xzf app-1.0.tar.gz && cd app-1.0
./configure --prefix=/usr/local
make -j$(nproc)
sudo make install
/usr/local/bin/app --version
```
`configure` проверяет окружение и создаёт Makefile, `make` собирает, `make install` устанавливает. `--prefix` задаёт каталог. Установка из исходников обходит пакетный менеджер.

## Задача 2. Применение патча

**Условие:** Примените патч к исходникам, проверьте изменения и откатите патч.

**Ожидаемый результат:** Патч применён и откачен.

**Решение и пояснения:**
```bash
sudo apt install -y patch
patch -p1 < fix.patch
grep -n "fix" src/*.c
patch -p1 -R < fix.patch      # Откат
diff -u orig.c new.c > my.patch   # Создание патча
```
`patch` применяет diff-файл, `-p1` отбрасывает уровень пути, `-R` откатывает. `diff -u` создаёт унифицированный патч. Патчи используют при сборке и распространении исправлений.

## Задача 3. Резервное копирование данных

**Условие:** Настройте ежедневный бэкап `/etc` и `/home` с ротацией за 7 дней.

**Ожидаемый результат:** Бэкап автоматизирован.

**Решение и пояснения:**
```bash
#!/bin/bash
D=/backup; F=$D/etc_$(date +%F).tar.gz
tar -czf "$F" /etc /home
find "$D" -name 'etc_*.tar.gz' -mtime +7 -delete
# cron: 0 2 * * * /usr/local/bin/backup.sh
```
Скрипт создаёт датированный архив и удаляет старые (>7 дней). Cron запускает ночью. Обязательно тестируйте восстановление, а не только создание бэкапа.

## Задача 4. Синхронизация с rsync

**Условие:** Настройте зеркалирование каталога на удалённый сервер с сохранением атрибутов.

**Ожидаемый результат:** Данные синхронизированы.

**Решение и пояснения:**
```bash
rsync -aAXv --delete /data/ user@backup:/backup/data/
# Через SSH с ключом и cron:
rsync -aAXz -e ssh --delete /data/ user@backup:/backup/data/
# Исключения: --exclude='*.tmp' --exclude='cache/'
```
rsync копирует только изменения, сохраняет права/ACL (`-aAX`), сжимает (`-z`). `--delete` удаляет лишнее в приёмнике. Эффективен для регулярной синхронизации.

## Задача 5. Уведомление пользователей

**Условие:** Перед плановым обслуживанием уведомите всех пользователей и запланируйте перезагрузку.

**Ожидаемый результат:** Пользователи уведомлены.

**Решение и пояснения:**
```bash
who ; w
echo "Обслуживание через 15 минут" | wall
sudo shutdown -r +15 "Плановый перезапуск"
sudo shutdown -c      # Отмена
# Изменение motd: /etc/update-motd.d/99-custom
```
`wall` рассылает всем, `shutdown +15` уведомляет и планирует. `shutdown -c` отменяет. Уведомление предотвращает потерю данных пользователями.

## Задача 6. Восстановление системы из бэкапа

**Условие:** Восстановите удалённый каталог `/etc/nginx` из архива и проверьте конфигурацию.

**Ожидаемый результат:** Каталог восстановлен, сервис работает.

**Решение и пояснения:**
```bash
tar -tzf /backup/etc_2024-01-01.tar.gz | grep nginx   # Содержимое
tar -xzf /backup/etc_2024-01-01.tar.gz -C / etc/nginx
sudo nginx -t
sudo systemctl reload nginx
```
Просмотр содержимого (`-t`) перед распаковкой — хорошая практика. Восстановление в `/` (`-C /`) возвращает файлы на место. После восстановления проверяют конфигурацию и перезапускают сервис.
