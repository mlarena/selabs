**Практическая работа №1: Перенаправление потоков**

**Задание:**
1. Перенаправьте стандартный вывод команды `ls /` в файл `out.txt`.
2. Перенаправьте стандартный поток ошибок в файл `err.txt`.
3. Объедините stdout и stderr в один файл `all.txt`.
4. Допишите вывод команды `date` в конец `out.txt`.
5. Подавьте вывод ошибок в `/dev/null`.

**Решение и пояснения:**
```bash
ls / > out.txt                    # 1. stdout в файл (перезапись)
ls /nonexistent 2> err.txt        # 2. stderr в файл
ls / /nonexistent &> all.txt      # 3. stdout+stderr в один файл
date >> out.txt                   # 4. Дозапись в конец
ls /nonexistent 2> /dev/null      # 5. Подавление ошибок
```
**Пояснения:**
Дескрипторы: 0 — stdin, 1 — stdout, 2 — stderr. `>` перезаписывает, `>>` дописывает. `2>` перенаправляет только ошибки, `&>` — оба потока. `/dev/null` — «чёрная дыра» для ненужного вывода.

**Практическая работа №2: Конвейеры (pipes)**

**Задание:**
1. Выведите список процессов, отсортированный по памяти.
2. Оставьте только 5 самых прожорливых процессов.
3. Посчитайте количество файлов в `/etc`.
4. Найдите пользователей с оболочкой `/bin/bash` в `/etc/passwd`.
5. Объясните, как работает конвейер из трёх команд.

**Решение и пояснения:**
```bash
ps aux | sort -k4 -nr | head -5                 # 1-2. Топ-5 по памяти
ls /etc | wc -l                                  # 3. Количество файлов
awk -F: '$7=="/bin/bash"{print $1}' /etc/passwd  # 4. Пользователи bash
```
**Пояснения:**
Символ `|` соединяет stdout одной команды со stdin следующей. В `ps aux | sort | head` данные последовательно фильтруются: список процессов → сортировка → первые 5 строк. Конвейеры позволяют строить мощные однострочники.

**Практическая работа №3: Команда tee и xargs**

**Задание:**
1. Выведите список файлов так, чтобы он шёл и на экран, и в файл.
2. Допишите результат в конец файла, не затирая его.
3. Передайте список файлов из файла в команду `rm` через `xargs`.
4. Создайте 5 файлов одной командой через `xargs`.
5. Объясните, зачем нужен `xargs`.

**Решение и пояснения:**
```bash
ls /etc | tee listing.txt            # 1. На экран и в файл
ls /var | tee -a listing.txt         # 2. Дозапись (-a append)
cat to_delete.txt | xargs rm -v      # 3. Список файлов -> аргументы rm
seq 1 5 | xargs -I{} touch file{}.txt   # 4. Создание 5 файлов
```
**Пояснения:**
`tee` разветвляет поток: пишет и в stdout, и в файл. `xargs` превращает строки со stdin в аргументы команды. Это нужно, когда команда не читает stdin, а принимает список файлов как аргументы (`rm`, `touch`).

**Практическая работа №4: Подстановка команд и здесь-документы**

**Задание:**
1. Используйте результат команды как аргумент (через обратные кавычки).
2. Сделайте то же через `$()`.
3. Создайте файл с помощью here-document.
4. Передайте многострочный текст в команду через конвейер.
5. Объясните разницу между одинарными и двойными кавычками.

**Решение и пояснения:**
```bash
echo "Сегодня: `date +%F`"          # 1. Подстановка через backticks
echo "Сегодня: $(date +%F)"         # 2. Подстановка через $()
cat > note.txt <<EOF                # 3. Here-document
Строка 1
Строка 2
EOF
echo -e "a\nb" | grep b             # 4. Многострочный ввод через конвейер
```
**Пояснения:**
`$(...)` и обратные кавычки подставляют вывод команды. Here-document (`<<EOF`) передаёт многострочный текст как stdin. В двойных кавычках переменные и подстановки раскрываются, в одинарных — нет (литерально).
