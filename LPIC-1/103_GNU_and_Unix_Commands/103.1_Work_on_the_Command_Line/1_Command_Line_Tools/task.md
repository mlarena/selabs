**Практическая работа №1: Основные команды навигации**

**Задание:**     
1. Подключитесь к системе Debian через терминал.   
2. Определите текущий каталог.    
3. Перейдите в корневой каталог (`/`).    
4. Выведите список файлов и подкаталогов в детализированном виде.    
5. Создайте в домашнем каталоге директорию `test_lab1`.    
6. Перейдите в созданный каталог и создайте в нем пустой файл `report.txt`.   
7. Подтвердите создание файла, выведя список содержимого `test_lab1`.    

**Решение и пояснения:**
```bash
pwd                    # 2. Показывает текущий рабочий каталог
cd /                   # 3. Переход в корневой каталог
ls -la                 # 4. Подробный список файлов (включая скрытые)
cd ~                   # Возврат в домашний каталог
mkdir test_lab1        # 5. Создание директории
cd test_lab1           # 6. Переход в неё
touch report.txt       # 6. Создание пустого файла
ls -l                  # 7. Проверка: покажет report.txt
```
**Пояснения:**      
`pwd` (print working directory) показывает, где вы находитесь.      
`ls -la` выводит детализированный список. 
`mkdir` создает директорию,      
`touch` — пустой файл. 
`cd` без аргументов или с `~` ведет в домашний каталог.

**Практическая работа №2: Работа с файлами и текстом**          
 
**Задание:**     
1. В каталоге `~/test_lab2` создайте файл `data.log` с содержимым из 5 строк (любой текст).      
2. Выведите первые 3 строки файла.      
3. Выведите последние 2 строки файла.     
4. Найдите в файле строки, содержащие слово "error" (без учета регистра).      
5. Подсчитайте количество строк в файле.     
6. Создайте копию файла с именем `data_backup.log`.     
7. Подсчитайте количенство строк "error" в файле `data_backup.log`     

**Решение и пояснения:**
```bash
mkdir ~/test_lab2 && cd ~/test_lab2
echo -e "Line 1\nLine 2\nLine 3\nerror: failed\nLine 5" > data.log  # 1
head -n 3 data.log                      # 2. Первые 3 строки
tail -n 2 data.log                      # 3. Последние 2 строки
grep -i error data.log                  # 4. Поиск "error" (регистр неважен)
wc -l data.log                          # 5. Подсчет строк (вывод: 5)
cp data.log data_backup.log             # 6. Копирование
grep -i error data_backup.log  | wc -l  #7. Подсчет строк "error"     
```
**Пояснения:**      
`echo -e` с `\n` создает многострочный файл.      
`head`/`tail` выводят начало/конец файла.      
`grep -i` ищет с игнорированием регистра.      
`wc -l` считает строки.      
`cp` копирует файл.

**Практическая работа №3: Права доступа и процессы**     

**Задание:**     
1. В домашнем каталоге создайте файл `script.sh` с одной строкой: `#!/bin/bash`.     
2. Сделайте файл исполняемым для владельца.     
3. Запустите в фоне процесс `sleep 300`.     
4. Найдите идентификатор (PID) процесса `sleep`.     
5. Завершите процесс `sleep` с помощью его PID.     
6. Измените права на файл `script.sh`, чтобы все пользователи могли его читать и выполнять.     

**Решение и пояснения:**
```bash
cd ~
echo '#!/bin/bash' > script.sh       # 1. Создание файла
chmod u+x script.sh                  # 2. +x (выполнение) для владельца
sleep 300 &                          # 3. Запуск в фоне (вернет PID)
ps aux | grep sleep                  # 4. Поиск PID процесса sleep
kill <PID>                           # 5. Подставьте найденный PID
chmod a+rx script.sh                 # 6. Права на чтение и выполнение для всех
```
**Пояснения:**      
`chmod u+x` добавляет право на выполнение для пользователя. 
`&` запускает процесс в фоне.      
`ps aux | grep` ищет процесс.      
`kill` завершает процесс по PID.      
`chmod a+rx` дает права всем (a = all).

**Практическая работа №4: Перенаправление и архивация**     

**Задание:**     
1. Создайте каталог `~/archive_lab`.     
2. Внутри создайте 3 текстовых файла: `app.log`, `sys.log`, `user.log` с произвольным содержимым.     
3. Объедините содержимое всех трех файлов в один `combined.log`.     
4. Заархивируйте все `.log` файлы в `logs.tar.gz`.     
5. Удалите оригинальные `.log` файлы, оставив только архив.     
6. Проверьте список файлов в архиве без его распаковки.     
7. Объединять файлы в строгой последовательности - data.log app.log sys.log      
8. Распаковать содержимое в папку  ~/archive_lab/arh_lab     

**Решение и пояснения:**
```bash
mkdir ~/archive_lab && cd ~/archive_lab
echo "App data" > app.log                     # 2. Создание файлов
echo "System data" > sys.log
echo "User data" > user.log
cat *.log > combined.log                      # 3. Объединение в один файл
tar -czf logs.tar.gz *.log                    # 4. Создание архива .tar.gz
rm *.log                                      # 5. Удаление исходных файлов
tar -tzf logs.tar.gz                          # 6. Просмотр содержимого архива
cat data.log app.log sys.log > combined2.log  # 7. Объединяем файлы в строгой последовательности
tar -xzf logs.tar.gz -C ~/archive_lab/arh_lab

```
**Пояснения:**      
`cat *.log > combined.log` читает все `.log` файлы и перенаправляет вывод в `combined.log`.      
`tar -czf` создает сжатый архив (c = create, z = gzip, f = file).       
`rm *.log` удаляет файлы по маске.       
`tar -tzf` выводит список файлов в архиве без распаковки.
