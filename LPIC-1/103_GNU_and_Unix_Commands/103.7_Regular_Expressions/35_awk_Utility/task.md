**Практическая работа №1: Базовые операции с awk**      

**Задание:**     
1. Создайте файл `data.txt` с таблицей данных (пример ниже).      
2. Выведите первый и третий столбцы.      
3. Выведите строки, где второй столбец больше 30.     
4. Подсчитайте сумму значений в третьем столбце.      
5. Найдите среднее значение второго столбца.       
6. Выведите общее количество строк в файле.      

**Решение и пояснения:**
```bash
# 1. Создание тестового файла
echo -e "Иван 25 50000\nПетр 35 75000\nАнна 28 60000\nМария 40 90000" > data.txt

# 2. Вывод первого и третьего столбцов
awk '{print $1, $3}' data.txt

# 3. Строки, где возраст > 30
awk '$2 > 30 {print $0}' data.txt

# 4. Сумма зарплат (третий столбец)
awk '{sum+=$3} END {print "Сумма:", sum}' data.txt

# 5. Средний возраст
awk '{sum+=$2; count++} END {print "Средний возраст:", sum/count}' data.txt

# 6. Количество строк
awk 'END {print "Всего строк:", NR}' data.txt
```
**Пояснения:**       
Awk автоматически разбивает строки на поля (столбцы) по пробелам.       
`$1`, `$2`, `$3` — первый, второй, третий столбцы.       
`$0` — вся строка.       
`NR` — номер текущей строки, в блоке `END` содержит общее количество строк.              
`END` выполняется после обработки всех строк.

**Практическая работа №2: Форматирование и фильтрация**     

**Задание:**    
1. Выведите данные в формате "Имя (возраст лет)".      
2. Добавьте заголовок к таблице.        
3. Отсортируйте вывод по возрасту (второй столбец).      
4. Найдите максимальную зарплату.      
5. Отфильтруйте строки, где имя начинается на "А".       
6. Добавьте нумерацию строк в выводе.      

**Решение и пояснения:**
```bash
# 1. Форматированный вывод
awk '{print $1 " (" $2 " лет)"}' data.txt

# 2. С заголовком
awk 'BEGIN {print "Имя\tВозраст\tЗарплата"} {print $0}' data.txt

# 3. Сортировка по второму столбцу (возраст)
awk '{print $2, $0}' data.txt | sort -n | cut -d' ' -f2-

# 4. Максимальная зарплата
awk 'max<$3 {max=$3} END {print "Макс. зарплата:", max}' data.txt

# 5. Имена на "А"
awk '$1 ~ /^А/ {print $0}' data.txt

# 6. С нумерацией
awk '{print NR ". " $0}' data.txt
```
**Пояснения:**        
`BEGIN` выполняется перед обработкой строк.       
`~ /^А/` — регулярное выражение для поиска строк, начинающихся на "А".      
Сортировка через `sort -n` после добавления ключа.       
`max<$3 {max=$3}` сохраняет максимальное значение третьего столбца.

**Практическая работа №3: Работа с разделителями и массивами**    

**Задание:**    
1. Используйте файл `/etc/passwd` (разделитель `:`).     
2. Выведите имена пользователей и их shell.     
3. Подсчитайте количество пользователей с shell `/bin/bash`.     
4. Создайте ассоциативный массив для подсчета shell.     
5. Выведите уникальные shell из файла.      
6. Найдите пользователей с UID > 1000.     

**Решение и пояснения:**
```bash
# 1-2. Пользователи и их shell (поля 1 и 7)
awk -F: '{print $1 " использует " $7}' /etc/passwd

# 3. Количество пользователей с /bin/bash
awk -F: '$7 == "/bin/bash" {count++} END {print "Пользователей с bash:", count}' /etc/passwd      

# 4-5. Уникальные shell через массив    
awk -F: '{shells[$7]++} END {for(s in shells) print s, shells[s]}' /etc/passwd     

# 6. Пользователи с UID > 1000
awk -F: '$3 > 1000 {print $1 " (UID:" $3 ")"}' /etc/passwd     
```
**Пояснения:** `-F:` устанавливает разделитель `:`. Ассоциативные массивы `shells[$7]++` подсчитывают количество каждого shell. Цикл `for(s in shells)` перебирает индексы массива. В `/etc/passwd` третье поле — UID пользователя.

**Практическая работа №4: Комбинирование с другими утилитами**     

**Задание:**   
1. Используйте вывод `ps aux` для анализа процессов.       
2. Найдите топ-5 процессов по использованию памяти.    
3. Подсчитайте общее использование памяти всеми процессами.    
4. Найдите процессы определенного пользователя.    
5. Создайте отчет о запущенных службах.     
6. Напишите скрипт для мониторинга системных ресурсов.     

**Решение и пояснения:**
```bash
# 1-2. Топ-5 по памяти (поле 6 в ps aux)
ps aux | awk '{print $6/1024 " MB", $11}' | sort -nr | head -5

# 3. Общее использование памяти (в MB)
ps aux | awk '{sum+=$6} END {print "Общая память:", sum/1024 " MB"}'

# 4. Процессы пользователя www-data
ps aux | awk '$1 == "www-data" {print $0}'

# 5. Отчет о службах
systemctl list-units --type=service | awk '/loaded/ {print $1, $3}' > services_report.txt

# 6. Скрипт мониторинга monitor.awk
#!/usr/bin/awk -f
BEGIN {print "=== Мониторинг ==="}
{count++}
END {print "Обработано строк:", count}
# Запуск: awk -f monitor.awk /proc/meminfo
```
**Пояснения:** `ps aux` показывает процессы: поле 6 — RSS (память) в KB. Деление на 1024 переводит в MB. Awk может быть интерпретатором скрипта (шебанг `#!/usr/bin/awk -f`). Комбинирование с `sort` и `head` дает гибкость в анализе.
