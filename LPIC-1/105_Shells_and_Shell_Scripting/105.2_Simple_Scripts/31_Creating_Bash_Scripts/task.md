**Практическая работа №1: Базовый скрипт с переменными и вводом**    

**Задание:**    
1. Создайте скрипт, который запрашивает имя пользователя.    
2. Сохраните ввод в переменную.    
3. Выведите приветствие с именем пользователя и текущей датой.    
4. Добавьте проверку: если имя не введено, выведите ошибку.    
5. Используйте переменные окружения для вывода информации о системе.    
6. Сделайте скрипт исполняемым и запустите его.    

**Решение и пояснения:**
```bash
#!/bin/bash
# script1.sh
echo "Введите ваше имя:"
read username  # 2. Чтение ввода в переменную

if [ -z "$username" ]; then  # 4. Проверка на пустой ввод
    echo "Ошибка: имя не введено!"
    exit 1
fi

echo "Привет, $username!"  # 3. Вывод с переменной
echo "Сегодня: $(date)"  # 3. Вывод даты
echo "Ваш shell: $SHELL"  # 5. Использование переменной окружения

# 6. Сделать исполняемым: chmod +x script1.sh
# Запуск: ./script1.sh
```
**Пояснения:**     
`#!/bin/bash` — шебанг, указывает интерпретатор.     
`read` читает пользовательский ввод.     
`[ -z "$var" ]` проверяет, пуста ли переменная.     
`$(date)` выполняет команду и подставляет результат.     
`$SHELL` — системная переменная окружения.     
`exit 1` завершает скрипт с кодом ошибки.

**Практическая работа №2: Условные операторы и арифметика**

**Задание:**    
1. Создайте скрипт, который принимает число как аргумент.    
2. Проверьте, является ли число положительным, отрицательным или нулем.    
3. Проверьте, четное число или нечетное.    
4. Сравните два числа, переданных как аргументы.    
5. Выполните базовые арифметические операции.    
6. Обработайте случай, когда аргументы не переданы.    

**Решение и пояснения:**
```bash
#!/bin/bash
# script2.sh
if [ $# -eq 0 ]; then  # 6. Проверка количества аргументов
    echo "Использование: $0 <число> [число2]"
    exit 1
fi

# 2. Проверка знака числа
if [ $1 -gt 0 ]; then
    echo "$1 - положительное"
elif [ $1 -lt 0 ]; then
    echo "$1 - отрицательное"
else
    echo "$1 - ноль"
fi

# 3. Проверка четности
if [ $(($1 % 2)) -eq 0 ]; then
    echo "$1 - четное"
else
    echo "$1 - нечетное"
fi

# 4. Сравнение двух чисел
if [ $# -ge 2 ]; then
    if [ $1 -gt $2 ]; then
        echo "$1 > $2"
    elif [ $1 -lt $2 ]; then
        echo "$1 < $2"
    else
        echo "$1 = $2"
    fi
    # 5. Арифметические операции
    echo "Сумма: $(($1 + $2))"
    echo "Разность: $(($1 - $2))"
fi
```
**Пояснения:**     
`$#` — количество аргументов.     
`$1`, `$2` — первый и второй аргументы.     
`-gt`, `-lt`, `-eq` — операторы сравнения.     
`$(($1 % 2))` — арифметическая операция (остаток от деления).     
Двойные скобки `(( ))` используются для арифметических вычислений.

**Практическая работа №3: Циклы for и while**    

**Задание:**    
1. Создайте скрипт, который выводит числа от 1 до 10.    
2. Переберите все файлы в текущем каталоге и выведите их имена.    
3. Переберите аргументы, переданные скрипту.    
4. Используйте while для чтения файла построчно.    
5. Создайте бесконечный цикл с выходом по условию.    
6. Используйте цикл для создания резервных копий файлов.    

**Решение и пояснения:**
```bash
#!/bin/bash
# script3.sh

# 1. Цикл for для чисел
for i in {1..10}; do
    echo "Число: $i"
done

# 2. Цикл for для файлов
echo "Файлы в каталоге:"
for file in *; do
    [ -f "$file" ] && echo "Файл: $file"  # Проверка, что это файл
done

# 3. Цикл for для аргументов
echo "Аргументы:"
for arg in "$@"; do
    echo "Аргумент: $arg"
done

# 4. Цикл while для чтения файла
echo "Первые 3 строки /etc/passwd:"
count=0
while read line && [ $count -lt 3 ]; do
    echo "$line"
    ((count++))
done < /etc/passwd

# 5. Бесконечный цикл с break
counter=0
while true; do
    echo "Итерация $counter"
    ((counter++))
    [ $counter -ge 5 ] && break  # Выход после 5 итераций
done
```
**Пояснения:**     
`for i in {1..10}` — диапазон чисел.     
`for file in *` — все файлы в каталоге. 
`"$@"` — все аргументы скрипта.     
`while read line` читает файл построчно.     
`break` прерывает цикл.     
`< /etc/passwd` перенаправляет ввод в цикл.

**Практическая работа №4: Функции и обработка ошибок**

**Задание:**    
1. Создайте функцию для проверки существования файла.    
2. Создайте функцию для создания резервной копии файла.    
3. Добавьте обработку ошибок с помощью trap.    
4. Используйте функцию для рекурсивного подсчета файлов.    
5. Создайте лог-файл действий скрипта.    
6. Добавьте аргументы командной строки с getopts.    

**Решение и пояснения:**
```bash
#!/bin/bash
# script4.sh
LOG="script.log"

# 3. Обработка ошибок
trap "echo 'Скрипт прерван' >> $LOG; exit 1" SIGINT SIGTERM

# 1. Функция проверки файла
check_file() {
    if [ ! -f "$1" ]; then
        echo "Файл $1 не существует" >> $LOG
        return 1
    fi
    return 0
}

# 2. Функция резервного копирования
backup_file() {
    check_file "$1" || return 1
    local backup="$1.backup_$(date +%Y%m%d)"
    cp "$1" "$backup"
    echo "Создана резервная копия: $backup" >> $LOG
}

# 4. Функция подсчета файлов
count_files() {
    find "$1" -type f 2>/dev/null | wc -l
}

# 6. Обработка аргументов
while getopts "f:l:" opt; do
    case $opt in
        f) backup_file "$OPTARG" ;;
        l) LOG="$OPTARG" ;;
        *) echo "Неверный аргумент" ;;
    esac
done

# 5. Использование функций
echo "Скрипт запущен $(date)" > $LOG
backup_file "/etc/hosts"
echo "Файлов в /etc: $(count_files /etc)" >> $LOG
```
**Пояснения:**     
Функции определяются через `function_name() { ... }`.     
`trap` перехватывает сигналы (Ctrl+C = SIGINT).     
`getopts` обрабатывает аргументы командной строки.     
`local` создает локальную переменную функции.     
`2>/dev/null` скрывает ошибки find.     
Логирование помогает отслеживать выполнение скрипта.
