**Практическая работа №1: Базовый мониторинг оперативной памяти**

**Задание:**      
1. Покажите общую информацию об использовании оперативной памяти.      
2. Выведите информацию в удобочитаемом формате (MB/GB).      
3. Определите, сколько памяти свободно и доступно.      
4. Покажите использование swap-раздела.      
5. Отслеживайте использование памяти в реальном времени.      
6. Создайте алиас `mem` для быстрой проверки памяти.      

**Решение и пояснения:**
```bash
free                          # 1. Общая информация о памяти
free -h                       # 2. Human-readable формат (MB/GB)
free -h | grep Mem | awk '{print "Свободно: "$4", Доступно: "$7}'  # 3
free -h | grep Swap           # 4. Информация о swap
watch -n 2 'free -h'          # 5. Обновление каждые 2 секунды
alias mem='free -h'           # 6. Алиас для быстрой проверки
```

**Пояснения:**       
`free` показывает общее, использованное и свободное ОЗУ.       
`-h` форматирует вывод.       
`Доступно` (available) — память, которую можно использовать без свапа.       
`watch` обновляет команду периодически. Swap — виртуальная память на диске.

**Практическая работа №2: Детальный анализ использования памяти процессами**      

**Задание:**      
1. Покажите топ-5 процессов по потреблению памяти.      
2. Отсортируйте процессы по использованию памяти (от большего к меньшему).      
3. Определите, сколько памяти использует конкретный процесс (например, `bash`).      
4. Покажите суммарное использование памяти всеми процессами пользователя.      
5. Найдите процессы, потребляющие более 100MB RAM.      
6. Отслеживайте изменения использования памяти процессами.      

**Решение и пояснения:**
```bash
ps aux --sort=-%mem | head -6          # 1,2. Топ-5 процессов (1 строка — заголовок)
ps aux | grep bash | awk '{print $6/1024 " MB"}'  # 3. Память bash в MB
ps -u $USER -o rss | awk '{sum+=$1} END {print sum/1024 " MB"}'  # 4. Сумма по пользователю
ps aux | awk '$6 > 100000 {print $11, $6/1024 "MB"}'  # 5. Процессы >100MB (в KB)
top -o %MEM                           # 6. Интерактивный мониторинг (q для выхода)
```
**Пояснения:** 
`ps aux` показывает все процессы.       
`--sort=-%mem` сортирует по убыванию использования памяти.       
`$6` в `ps aux` — RSS в килобайтах.       
`awk '$6 > 100000'` ищет процессы с RSS > 100,000KB (~100MB).       
`top -o %MEM` сортирует процессы по памяти в реальном времени.

**Практическая работа №3: Настройка мониторинга и алертов**      

**Задание:**      
1. Напишите скрипт, который проверяет использование памяти.      
2. Если свободной памяти меньше 10%, выводите предупреждение.      
3. Добавьте проверку swap (если используется более 50%).      
4. Скрипт должен показывать текущую дату и статистику в %.      
5. Найдите процессы, которые можно "убить" при нехватке памяти.      
6. Настройте ежечасный запуск скрипта через cron.      

**Решение и пояснения:**
```bash
#!/bin/bash
# check_mem.sh
MEM_FREE=$(free | grep Mem | awk '{printf "%.0f", $4/$2 * 100}')  # 1. % свободной памяти
SWAP_USED=$(free | grep Swap | awk '{if ($2!=0) printf "%.0f", $3/$2 * 100; else print "0"}')

echo "$(date): Свободно RAM: $MEM_FREE%, Swap used: $SWAP_USED%"  # 4

if [ $MEM_FREE -lt 10 ]; then       # 2. <10% свободной памяти
  echo "ВНИМАНИЕ: Мало свободной памяти!"
fi

if [ $SWAP_USED -gt 50 ]; then      # 3. >50% swap используется
  echo "ВНИМАНИЕ: Активно используется swap!"
fi

ps aux --sort=-%mem | head -10      # 5. Кандидаты для завершения
```
**Пояснения:**       
`$4/$2 * 100` вычисляет процент свободной памяти.             
`-lt` = less than.       
`-gt` = greater than. Процессы, отсортированные по `%mem`, помогут найти "пожирателей" памяти.       
Для cron: `crontab -e` → `0 * * * * /path/to/check_mem.sh`

**Практическая работа №4: Очистка и оптимизация памяти**

**Задание:**      
1. Очистите кэш страниц памяти (без потери данных).      
2. Проверьте, сколько памяти освободилось.      
3. Определите, какие типы кэша используют память.      
4. Очистите slab-кэш (кэш структур ядра).      
5. Освободите память, используемую неиспользуемыми библиотеками.      
6. Создайте скрипт для безопасной очистки кэша.      

**Решение и пояснения:**
```bash
free -h && sync && echo 3 | sudo tee /proc/sys/vm/drop_caches  # 1. Очистка кэша
free -h                         # 2. Проверка освобожденной памяти
sudo slabtop                    # 3. Просмотр slab-кэша (q для выхода)
echo 2 | sudo tee /proc/sys/vm/drop_caches  # 4. Очистка slab-кэша
sudo apt install preload && sudo systemctl restart preload  # 5. Оптимизация загрузки
cat /proc/meminfo | grep -E "(Cached|Buffers|Slab)"  # Детальная информация
```
**Пояснения:** 
`sync` записывает данные на диск.       
`echo 3 > /proc/sys/vm/drop_caches` очищает кэш страниц, dentries и inodes.       
`1` — страницы,       
`2` — dentries и inodes,       
`3` — всё. **Важно:** Очистка кэша временно замедляет систему.       
`slabtop` показывает кэш структур ядра.       
`preload` предзагружает часто используемые библиотеки.
