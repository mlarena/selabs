**Практическая работа №1: Настройка сетевого интерфейса**

**Задание:**
1. Посмотрите сетевые интерфейсы.
2. Назначьте IP-адрес интерфейсу.
3. Добавьте дополнительный адрес.
4. Включите и выключите интерфейс.
5. Объясните разницу между `ip` и `ifconfig`.

**Решение и пояснения:**
```bash
ip link show                              # 1. Интерфейсы
sudo ip addr add 192.168.50.10/24 dev eth0   # 2. Адрес
sudo ip addr add 192.168.51.10/24 dev eth0   # 3. Доп. адрес
sudo ip link set eth0 down                # 4. Выключить
sudo ip link set eth0 up                  # 4. Включить
```
**Пояснения:**
`ip` (iproute2) — современный инструмент, заменяет `ifconfig`/`route`/`arp` (net-tools). `ip addr` управляет адресами, `ip link` — состоянием интерфейса. Изменения не сохраняются после перезагрузки без конфигурации.

**Практическая работа №2: Маршрутизация**

**Задание:**
1. Посмотрите таблицу маршрутизации.
2. Добавьте статический маршрут.
3. Установите шлюз по умолчанию.
4. Удалите маршрут.
5. Объясните принцип выбора маршрута.

**Решение и пояснения:**
```bash
ip route show                              # 1. Таблица маршрутов
sudo ip route add 10.10.0.0/16 via 192.168.50.1   # 2. Статический маршрут
sudo ip route add default via 192.168.50.1        # 3. Шлюз по умолчанию
sudo ip route del 10.10.0.0/16                    # 4. Удаление
```
**Пояснения:**
Маршрутизация выбирает путь по принципу longest prefix match (наиболее специфичный маршрут). `default` — маршрут для всего остального. `ip route get <ip>` показывает, каким маршрутом пойдёт пакет.

**Практическая работа №3: Беспроводные сети**

**Задание:**
1. Проверьте наличие беспроводного интерфейса.
2. Посмотрите доступные точки доступа.
3. Подключитесь к открытой сети.
4. Подключитесь к сети WPA2.
5. Объясните разницу `iw` и `iwconfig`.

**Решение и пояснения:**
```bash
iw dev                                     # 1. Wireless-интерфейсы
sudo iw dev wlan0 scan | grep SSID         # 2. Точки доступа
sudo iw dev wlan0 connect Guest            # 3. Открытая сеть
# WPA2 через wpa_supplicant:
wpa_passphrase MyNet 'password' | sudo tee /etc/wpa_supplicant.conf
sudo wpa_supplicant -B -i wlan0 -c /etc/wpa_supplicant.conf
sudo dhclient wlan0
```
**Пояснения:**
`iw` — современный инструмент для wireless (nl80211), `iwconfig` — устаревший (wireless extensions). Для WPA/WPA2 используют `wpa_supplicant`. Часто всё это управляется через NetworkManager.

**Практическая работа №4: Мультихоумный хост**

**Задание:**
1. Настройте два интерфейса с адресами в разных подсетях.
2. Проверьте таблицу маршрутов.
3. Настройте маршрут для второй подсети.
4. Проверьте доступность из обеих подсетей.
5. Объясните политику маршрутизации (policy routing).

**Решение и пояснения:**
```bash
sudo ip addr add 10.0.1.1/24 dev eth1
sudo ip addr add 10.0.2.1/24 dev eth2
ip route show
# Маршрут для второй сети через конкретный интерфейс:
sudo ip route add 10.0.3.0/24 via 10.0.2.2 dev eth2
```
**Пояснения:**
Мультихоумный хост имеет адреса в нескольких сетях и может маршрутизировать между ними. Для сложных случаев применяют policy routing (`ip rule`, несколько таблиц), чтобы выбирать маршрут по источнику/признакам.
