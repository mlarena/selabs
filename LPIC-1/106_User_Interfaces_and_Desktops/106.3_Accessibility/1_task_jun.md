**Практическая работа №1: Темы оформления и контрастность**

**Задание:**
1. Установите пакет тем с высокой контрастностью.
2. Посмотрите доступные темы оформления.
3. Установите крупный шрифт в окружении.
4. Проверьте доступные настройки специальных возможностей.
5. Объясните назначение контрастных тем.

**Решение и пояснения:**
```bash
sudo apt install -y gnome-themes-extra gnome-accessibility-themes   # 1
ls /usr/share/themes/ | grep -i contrast                            # 2
gsettings set org.gnome.desktop.interface text-scaling-factor 1.5   # 3. Крупный текст
gsettings list-keys org.gnome.desktop.a11y                          # 4
```
**Пояснения:**
Темы с высокой контрастностью (High Contrast) и крупные шрифты помогают пользователям с ослабленным зрением. `gsettings` управляет настройками GNOME, включая параметры доступности в схеме `org.gnome.desktop.a11y`.

**Практическая работа №2: Экранный диктор и лупа**

**Задание:**
1. Проверьте, установлен ли экранный диктор (Orca).
2. Запустите экранный диктор.
3. Включите экранную лупу.
4. Включите экранную клавиатуру.
5. Объясните, кому помогают эти инструменты.

**Решение и пояснения:**
```bash
sudo apt install -y orca            # 1. Экранный диктор
orca &                              # 2. Запуск диктора
gsettings set org.gnome.desktop.a11y.applications screen-magnifier-enabled true  # 3
gsettings set org.gnome.desktop.a11y.applications screen-keyboard-enabled true   # 4
```
**Пояснения:**
Orca — экранный диктор, озвучивающий интерфейс для незрячих пользователей. Экранная лупа увеличивает часть экрана для слабовидящих. Экранная клавиатура нужна пользователям, которые не могут работать с физической клавиатурой.

**Практическая работа №3: Настройки клавиатуры и мыши**

**Задание:**
1. Включите «залипание» клавиш (Sticky Keys).
2. Включите медленные клавиши (Slow Keys).
3. Включите управление указателем с клавиатуры (Mouse Keys).
4. Настройте задержку повтора клавиш.
5. Объясните назначение каждой настройки.

**Решение и пояснения:**
```bash
gsettings set org.gnome.desktop.a11y.keyboard stickykeys-enable true   # 1
gsettings set org.gnome.desktop.a11y.keyboard slowkeys-enable true     # 2
gsettings set org.gnome.desktop.a11y.keyboard mousekeys-enable true    # 3
gsettings set org.gnome.desktop.peripherals.keyboard delay 500         # 4
```
**Пояснения:**
Sticky Keys позволяет нажимать сочетания клавиш по очереди. Slow Keys игнорирует случайные краткие нажатия. Mouse Keys управляет курсором с цифровой клавиатуры. Задержка повтора регулирует начало автоповтора символов.

**Практическая работа №4: Инструменты доступности и автоматизация**

**Задание:**
1. Выведите все настройки доступности GNOME.
2. Включите распознавание голоса (если доступно).
3. Настройте жесты/нажатие вместо удержания.
4. Сохраните текущие настройки доступности в файл.
5. Объясните, как проверить доступность рабочего места.

**Решение и пояснения:**
```bash
gsettings list-recursively org.gnome.desktop.a11y        # 1. Все настройки
gsettings set org.gnome.desktop.a11y.mouse dwell-click-enabled true   # 3
gsettings list-recursively org.gnome.desktop.a11y > ~/a11y_backup.txt # 4
```
**Пояснения:**
`gsettings list-recursively` выводит все ключи и значения схемы. Dwell Click позволяет «кликать» задержкой указателя. Настройки можно сохранить и восстановить, что удобно при развёртывании рабочих мест для пользователей с ограниченными возможностями.
