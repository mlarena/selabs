**Практическая работа №1: Базовое управление историей команд**

**Задание:**      
1. Выведите последние 10 команд из истории.      
2. Найдите в истории все команды, содержащие `apt`.      
3. Очистите всю историю команд в текущей сессии.      
4. Выполните 3 новые команды (например, `date`, `pwd`, `ls`).      
5. Сохраните историю текущей сессии в файл `session_history.txt`.      
6. Установите размер истории на 5000 команд.      

**Решение и пояснения:**
```bash
history 10                           # 1. Последние 10 команд
history | grep apt                   # 2. Поиск по истории
history -c                           # 3. Очистка истории сессии
date                                 # 4. Выполняем команды
pwd                                  # 4.
ls                                   # 4.
history -w session_history.txt       # 5. Сохранение в файл
export HISTSIZE=5000                 # 6. Размер хранимой истории
```
**Пояснения:**       
`history` показывает список команд.       
`history N` — последние N команд.       
`history -c` очищает историю только в текущей сессии.       
`history -w` сохраняет историю в файл.       
`HISTSIZE` определяет, сколько команд хранить.

**Практическая работа №2: Настройка автосохранения истории**

**Задание:**      
1. Откройте файл `~/.bashrc` для настройки.      
2. Добавьте настройки для немедленного сохранения истории после каждой команды.      
3. Настройте игнорирование дублирующихся команд подряд.      
4. Настройте игнорирование команд, начинающихся с пробела.      
5. Примените изменения.      
6. Проверьте, что команда с пробелом в начале не сохраняется в историю.      

**Решение и пояснения:**
```bash
nano ~/.bashrc
# Добавьте в конец файла:
shopt -s histappend                   # 2. Добавлять, а не перезаписывать
export PROMPT_COMMAND="history -a"    # 2. Сохранять после каждой команды
export HISTCONTROL=ignoreboth         # 3,4. Игнорировать дубли и команды с пробелом
# Сохраните и выйдите
source ~/.bashrc                      # 5. Применить изменения
 ls                                   # 6. Обычная команда
  ls                                  # 6. Команда с пробелом (не сохранится)
history | tail -5                     # Проверка
```
**Пояснения:**       
`histappend` добавляет новые команды к файлу истории.       
`PROMPT_COMMAND` выполняется перед каждым промптом.       
`history -a` немедленно сохраняет команду.       
`HISTCONTROL=ignoreboth` игнорирует дубликаты и команды, начинающиеся с пробела.

**Практическая работа №3: Работа с файлом истории**

**Задание:**      
1. Определите путь к файлу истории команд.      
2. Создайте резервную копию файла истории с датой.      
3. Найдите 5 самых частых команд в истории.      
4. Удалите из истории все вхождения команды `secret_command`.      
5. Объедините историю из нескольких сессий, удалив дубликаты.      
6. Поищите в истории команды, выполненные вчера.      

**Решение и пояснения:**
```bash
echo $HISTFILE                        # 1. Путь к файлу истории (~/.bash_history)
cp $HISTFILE history_backup_$(date +%Y%m%d)  # 2. Резервная копия
cut -d' ' -f2- $HISTFILE | sort | uniq -c | sort -nr | head -5  # 3. Топ-5 команд
grep -v "secret_command" $HISTFILE > temp && mv temp $HISTFILE  # 4. Удаление строк
cat $HISTFILE | sort -u > combined_history  # 5. Объединение без дубликатов
grep "$(date -d "yesterday" +%Y-%m-%d)" $HISTFILE  # 6. Команды за вчера
```

**Пояснения:**       
`$HISTFILE` содержит путь к файлу истории. 
`cut -d' ' -f2-` удаляет номера команд из вывода       
`history`. `grep -v` инвертирует поиск (удаляет строки).       
`sort -u` оставляет только уникальные строки. 
Дата в истории сохраняется при правильной настройке `HISTTIMEFORMAT`.

**Практическая работа №4: Расширенные возможности истории**

**Задание:**      
1. Настройте отображение времени выполнения команд в истории.      
2. Используйте `Ctrl+R` для поиска команды `grep` в истории.      
3. Выполните предыдущую команду, начинающуюся с `ls`.      
4. Редактируйте последнюю команду (поменяйте `file.txt` на `document.txt`).      
5. Создайте алиас `h` для поиска по истории.      
6. Настройте сохранение истории с временными метками.      

**Решение и пояснения:**
```bash
export HISTTIMEFORMAT="%Y-%m-%d %T "  # 1. Формат времени
# Нажмите Ctrl+R, введите grep      # 2. Обратный поиск
!ls                                  # 3. Выполнит последнюю команду на ls
^file.txt^document.txt               # 4. Замена в предыдущей команде
alias h='history | grep'             # 5. Алиас для поиска
export HISTTIMEFORMAT="%d/%m/%y %T " # 6. Другой формат времени
history 5                            # Проверка с временем
```
**Пояснения:**       
`HISTTIMEFORMAT` добавляет временные метки.       
`Ctrl+R` — инкрементальный поиск по истории.       
`!ls` выполняет последнюю команду, начинающуюся с `ls`.       
`^old^new` заменяет текст в предыдущей команде. Временные метки помогают анализировать, когда команды были выполнены.
