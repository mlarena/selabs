**Практическая работа №1: Архитектура X11**

**Задание:**
1. Проверьте, запущен ли X-сервер.
2. Определите переменную окружения `DISPLAY`.
3. Посмотрите запущенные X-процессы.
4. Узнайте, какая графическая сессия активна.
5. Объясните роль X-сервера и X-клиента.

**Решение и пояснения:**
```bash
echo $DISPLAY                       # 2. Например :0
pgrep -a Xorg                       # 1-3. Процесс X-сервера
loginctl list-sessions              # 4. Активные сессии
loginctl show-session <ID> -p Type  # 4. Тип сессии (x11/wayland)
```
**Пояснения:**
В X11 сервер — это программа, управляющая дисплеем (обычно `Xorg`), а клиенты — приложения, рисующие окна. Переменная `DISPLAY` формата `host:display.screen` указывает, к какому серверу подключаться. `:0` — локальный первый дисплей.

**Практическая работа №2: Конфигурация Xorg**

**Задание:**
1. Посмотрите, есть ли файл `/etc/X11/xorg.conf`.
2. Найдите конфигурационные файлы в `/etc/X11/xorg.conf.d/`.
3. Создайте фрагмент с настройкой раскладки клавиатуры.
4. Проверьте журнал X-сервера на ошибки.
5. Объясните, зачем нужны фрагменты в `xorg.conf.d`.

**Решение и пояснения:**
```bash
ls /etc/X11/xorg.conf 2>/dev/null
ls /etc/X11/xorg.conf.d/
sudo tee /etc/X11/xorg.conf.d/00-keyboard.conf >/dev/null <<'EOF'
Section "InputClass"
    Identifier "system-keyboard"
    MatchIsKeyboard "on"
    Option "XkbLayout" "us,ru"
    Option "XkbOptions" "grp:alt_shift_toggle"
EndSection
EOF
grep -i "(EE)" ~/.local/share/xorg/Xorg.0.log 2>/dev/null
```
**Пояснения:**
Современный Xorg собирает конфигурацию из фрагментов `/etc/X11/xorg.conf.d/*.conf`; единый `xorg.conf` обычно не нужен. Секция `InputClass` настраивает устройства ввода. Журнал Xorg содержит строки `(EE)` — ошибки, `(WW)` — предупреждения.

**Практическая работа №3: Удалённый доступ к X**

**Задание:**
1. Разрешите доступ конкретному хосту через `xhost`.
2. Выведите текущий список разрешённых хостов.
3. Запустите приложение на удалённом хосте на локальном дисплее.
4. Отзовите доступ.
5. Объясните, почему `xhost` небезопасен.

**Решение и пояснения:**
```bash
xhost +si:localuser:$USER        # 1. Разрешить локального пользователя
xhost                            # 2. Список доступа
ssh -X user@remote xeyes         # 3. X11-форвардинг через SSH
xhost -si:localuser:$USER        # 4. Отзыв доступа
```
**Пояснения:**
`xhost` управляет доступом к X-серверу по хосту/пользователю. Прямой доступ (`xhost +`) небезопасен: любой может перехватывать нажатия клавиш и содержимое экрана. Безопаснее использовать `ssh -X` (X11-форвардинг с шифрованием).

**Практическая работа №4: Компоненты рабочего стола**

**Задание:**
1. Определите текущий дисплейный менеджер.
2. Узнайте, какое окружение рабочего стола установлено.
3. Определите оконный менеджер.
4. Проверьте, используется ли Wayland.
5. Объясните связь: дисплейный менеджер → сессия → оконный менеджер.

**Решение и пояснения:**
```bash
systemctl status display-manager       # 1. Дисплейный менеджер
echo $XDG_CURRENT_DESKTOP              # 2. Рабочее окружение
echo $XDG_SESSION_TYPE                 # 4. x11 или wayland
ps -e | grep -E "gnome-shell|xfwm|kwin|mutter"   # 3. Оконный менеджер
```
**Пояснения:**
Дисплейный менеджер (GDM, LightDM) показывает экран входа и запускает сессию. Сессия запускает окружение рабочего стола (GNOME, KDE, Xfce) и оконный менеджер. Wayland — современный протокол, заменяющий X11, где композитор совмещает роли сервера и оконного менеджера.
