**Практическая работа №1: Базовое архивирование и сжатие (tar, gzip)**     

**Задание:**     
1. Создайте архив домашнего каталога пользователя.     
2. Создайте архив с использованием сжатия gzip.     
3. Распакуйте архив в другую директорию.     
4. Просмотрите содержимое архива без распаковки.     
5. Добавьте файлы в существующий архив.     
6. Создайте архив только файлов, измененных за последние 7 дней.     

**Решение и пояснения:**     
```bash
tar -cf backup.tar ~/               # 1. Создание архива (без сжатия)
tar -czf backup.tar.gz ~/           # 2. Архив со сжатием gzip (-z)
tar -xzf backup.tar.gz -C /tmp/     # 3. Распаковка в /tmp
tar -tzf backup.tar.gz              # 4. Просмотр содержимого
tar -rf backup.tar newfile.txt      # 5. Добавление файла (только для несжатых архивов)
tar -czf recent.tar.gz ~/ -mtime -7  # 6. Только файлы последних 7 дней
```
**Пояснения:**      
`tar` — утилита для архивирования.      
`-c` — создать,      
`-x` — распаковать,      
`-t` — просмотреть,      
`-z` — gzip,      
`-j` — bzip2,      
`-J` — xz.      
`-f` указывает файл архива.      
`-C` указывает каталог для распаковки.      
`-mtime -7` фильтрует файлы по дате изменения.

**Практическая работа №2: Инкрементное резервное копирование с rsync**

**Задание:**     
1. Создайте полную резервную копию директории `/home` в `/backup`.     
2. Выполните инкрементное копирование (только изменения).     
3. Используйте `--dry-run` для проверки, что будет скопировано.     
4. Сохраняйте права файлов и ссылки при копировании.     
5. Удалите из резервной копии файлы, удаленные в источнике.     
6. Настройте исключение определенных файлов/папок из копирования.     

**Решение и пояснения:**
```bash
rsync -av /home/ /backup/full/      # 1. Рекурсивное копирование с сохранением атрибутов
rsync -av /home/ /backup/incremental/  # 2. Инкрементное копирование
rsync -av --dry-run /home/ /backup/  # 3. Пробный запуск без копирования
rsync -av --delete /home/ /backup/  # 5. Удаление удаленных файлов в бэкапе
rsync -av --exclude='*.tmp' /home/ /backup/  # 6. Исключение файлов .tmp
rsync -av --exclude-from=exclude.txt /home/ /backup/  # Исключение из файла
```
**Пояснения:** `rsync` копирует только изменившиеся файлы. `-a` (archive) сохраняет атрибуты, рекурсивно копирует. `-v` — подробный вывод. `--dry-run` показывает, что будет сделано. `--delete` синхронизирует удаления. `--exclude` исключает файлы по шаблону. Rsync эффективен для инкрементных бэкапов.

**Практическая работа №3: Работа с cpio и комбинированные архивы**

**Задание:**
1. Создайте архив cpio из списка файлов.
2. Распакуйте архив cpio.
3. Создайте архив cpio из вывода другой команды (например, `find`).
4. Создайте многоуровневый архив: tar + cpio + gzip.
5. Распакуйте сложный архив по шагам.
6. Проверьте целостность архива перед распаковкой.

**Решение и пояснения:**
```bash
ls ~/*.txt | cpio -ov > textfiles.cpio  # 1. Создание архива cpio из списка
cpio -idv < textfiles.cpio             # 2. Распаковка cpio
find ~/ -name "*.conf" -print0 | cpio -0ov > configs.cpio  # 3. Архив из find
tar -cf - ~/ | cpio -ov | gzip > combined_backup.tar.cpio.gz  # 4. Комбинированный
gzip -d combined_backup.tar.cpio.gz | cpio -id | tar -xf -  # 5. Распаковка в обратном порядке
gunzip -t backup.tar.gz               # 6. Проверка целостности gzip
```
**Пояснения:** `cpio` читает список файлов из stdin. `-o` — создание, `-i` — распаковка, `-v` — verbose, `-0` — для null-разделителей (с `find -print0`). Конвейер позволяет создавать сложные цепочки обработки. Проверка целостности важна перед распаковкой больших архивов.

**Практическая работа №4: Автоматизация резервного копирования**

**Задание:**
1. Напишите скрипт для ежедневного резервного копирования.
2. Сохраняйте архивы с датой в имени файла.
3. Настройте ротацию архивов (хранить только последние 7 дней).
4. Добавьте логирование операций.
5. Настройте отправку уведомлений при ошибках.
6. Запланируйте запуск скрипта через cron.

**Решение и пояснения:**
```bash
#!/bin/bash
# backup_script.sh
BACKUP_DIR="/backup"
SOURCE="/home"
DATE=$(date +%Y%m%d_%H%M%S)
LOG="/var/log/backup.log"

echo "$(date): Начало резервного копирования" >> $LOG
tar -czf "$BACKUP_DIR/backup_$DATE.tar.gz" "$SOURCE" 2>> $LOG

if [ $? -eq 0 ]; then
    echo "$(date): Резервная копия успешно создана" >> $LOG
else
    echo "$(date): Ошибка при создании резервной копии" >> $LOG
    # mail -s "Ошибка бэкапа" admin@example.com < $LOG
fi

# 3. Ротация: удалить архивы старше 7 дней
find "$BACKUP_DIR" -name "backup_*.tar.gz" -mtime +7 -delete >> $LOG

# 6. В crontab: 0 2 * * * /path/to/backup_script.sh
```
**Пояснения:** Скрипт создает датированные архивы. `2>> $LOG` перенаправляет ошибки в лог. Проверка `$?` определяет успешность операции. `find -mtime +7` находит файлы старше 7 дней. Cron-задание запускает скрипт ежедневно в 2:00. Логирование и уведомления помогают мониторить процесс.
