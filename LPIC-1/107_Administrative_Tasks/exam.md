# Экзаменационные боевые задачи — Тема 107: Administrative Tasks

Задачи приближены к реальным заданиям экзамена **102-500**.

## Задача 1. Управление пользователями и группами

**Условие:** Создайте пользователя `alice` с домашним каталогом, добавьте в группу `devs`, задайте пароль и срок действия.

**Ожидаемый результат:** Пользователь создан и настроен.

**Решение и пояснения:**
```bash
sudo useradd -m -s /bin/bash -c "Alice" alice
sudo passwd alice
sudo groupadd devs
sudo usermod -aG devs alice
sudo chage -M 90 alice
id alice ; chage -l alice
```
`useradd -m` создаёт домашний каталог, `usermod -aG` добавляет в группу, `chage` задаёт срок действия. `id` и `chage -l` проверяют настройки.

## Задача 2. Изменение и блокировка учётной записи

**Условие:** Заблокируйте учётную запись, затем разблокируйте и смените её логин.

**Ожидаемый результат:** Операции выполнены.

**Решение и пояснения:**
```bash
sudo usermod -L alice         # Блокировка
sudo passwd -S alice          # Статус
sudo usermod -U alice         # Разблокировка
sudo usermod -l alice2 alice  # Смена логина
sudo usermod -d /home/alice2 -m alice2   # Перемещение каталога
```
`-L`/`-U` блокируют/разблокируют (ставят/снимают `!` в хэше). `-l` меняет логин, `-d -m` перемещает домашний каталог.

## Задача 3. Планирование задач через cron

**Условие:** Настройте ежедневный бэкап `/home` в 2:00 и задачу для пользователя.

**Ожидаемый результат:** Задания в cron настроены.

**Решение и пояснения:**
```bash
# crontab -e:
0 2 * * * tar -czf /backup/home_$(date +\%F).tar.gz /home
# Формат: мин час день мес день_нед команда
crontab -l
# Системные: /etc/cron.d/, /etc/cron.daily/
ls /etc/cron.daily/
```
Формат cron: `минута час день месяц день_недели`. `crontab -e` — задания пользователя, `/etc/cron.d/` — системные. Для root — `sudo crontab -e`.

## Задача 4. Планирование одноразовых задач

**Условие:** Запланируйте выполнение команды через 10 минут с помощью `at`.

**Ожидаемый результат:** Задача добавлена в очередь.

**Решение и пояснения:**
```bash
echo "wall 'Обслуживание'" | at now + 10 minutes
atq                    # Список задач
atrm <job_number>      # Удаление
systemctl status atd   # Служба должна работать
```
`at` выполняет одноразовые задачи. `atq`/`atrm` управляют очередью. Требуется запущенный демон `atd`. В отличие от cron, `at` — разовая задача.

## Задача 5. Локализация и интернационализация

**Условие:** Посмотрите текущую локаль, установите русскую локаль и настройте её для системы.

**Ожидаемый результат:** Локаль установлена и применена.

**Решение и пояснения:**
```bash
locale
locale -a | grep -i ru
sudo dpkg-reconfigure locales    # Или: localedef -i ru_RU -f UTF-8 ru_RU.UTF-8
# /etc/default/locale: LANG=ru_RU.UTF-8
# /etc/locale.gen: раскомментировать ru_RU.UTF-8, затем locale-gen
export LANG=ru_RU.UTF-8
```
Локаль определяет язык, кодировку, форматы. `locale` показывает текущую, `locale -a` — доступные. Настройки в `/etc/default/locale` и `/etc/locale.gen`.

## Задача 6. Часовой пояс системы

**Условие:** Смените часовой пояс на Europe/Moscow и проверьте время.

**Ожидаемый результат:** Часовой пояс изменён.

**Решение и пояснения:**
```bash
timedatectl
sudo timedatectl set-timezone Europe/Moscow
date
ls -l /etc/localtime     # Симлинк на файл зоны
```
`timedatectl` управляет временем и часовым поясом. `/etc/localtime` — симлинк на `/usr/share/zoneinfo/<зона>`. `date` показывает текущее время.
