**Практическая работа №1: Образы ядра и их расположение**

**Задание:**
1. Определите текущую версию ядра.
2. Посмотрите файлы ядра в `/boot`.
3. Определите тип образа (vmlinuz, bzImage).
4. Посмотрите каталог модулей текущего ядра.
5. Объясните разницу между zImage и bzImage.

**Решение и пояснения:**
```bash
uname -r                                   # 1. Версия ядра
ls -lh /boot/vmlinuz-*                     # 2-3. Образы ядра
ls /lib/modules/$(uname -r)/               # 4. Модули ядра
file /boot/vmlinuz-$(uname -r)             # 3. Тип файла
```
**Пояснения:**
Ядро хранится в `/boot/vmlinuz-<версия>`. `zImage` — сжатый образ, размещаемый в младшей памяти; `bzImage` (big zImage) — для больших ядер и загрузки по адресу выше 1 МБ. Модули — в `/lib/modules/<версия>/`.

**Практическая работа №2: Работа с модулями ядра**

**Задание:**
1. Выведите список загруженных модулей.
2. Получите информацию о конкретном модуле.
3. Загрузите модуль вручную.
4. Выгрузите модуль.
5. Объясните зависимости модулей.

**Решение и пояснения:**
```bash
lsmod                              # 1. Загруженные модули
modinfo loop                       # 2. Информация о модуле
sudo modprobe loop                 # 3. Загрузка (с зависимостями)
sudo rmmod loop                    # 4. Выгрузка
modprobe --show-depends loop       # 5. Зависимости
```
**Пояснения:**
`lsmod` читает `/proc/modules`. `modinfo` показывает параметры, лицензию, зависимости. `modprobe` загружает модуль с учётом зависимостей (в отличие от `insmod`). `rmmod` выгружает модуль; выгрузка возможна, если модуль не используется.

**Практическая работа №3: Исходники и документация ядра**

**Задание:**
1. Установите исходники ядра.
2. Посмотрите структуру `/usr/src/linux`.
3. Найдите документацию по подсистеме.
4. Определите файл `.config`.
5. Объясните назначение каталога Documentation.

**Решение и пояснения:**
```bash
sudo apt install -y linux-source
tar -xf /usr/src/linux-source-*.tar.xz -C /usr/src/
ls /usr/src/linux-source-*/Documentation | head
ls /usr/src/linux-source-*/.config 2>/dev/null
```
**Пояснения:**
Исходники ядра содержат каталог `Documentation/` с описанием подсистем, драйверов и параметров загрузки. Файл `.config` задаёт конфигурацию сборки. Документация — важный источник при компиляции и отладке.

**Практическая работа №4: Сжатие и распаковка ядра**

**Задание:**
1. Определите, каким алгоритмом сжато текущее ядро.
2. Сравните размеры несжатого и сжатого образа.
3. Установите утилиту для работы с xz.
4. Распакуйте образ ядра (для анализа).
5. Объясните, зачем сжимать ядро.

**Решение и пояснения:**
```bash
file /boot/vmlinuz-$(uname -r)      # 1. Тип сжатия (gzip/xz/zstd)
ls -lh /boot/vmlinuz-$(uname -r)    # 2. Размер
xz --version                        # 3. Утилита xz
# Извлечение (упрощённо):
# extract-vmlinux /boot/vmlinuz-... > vmlinux
```
**Пояснения:**
Ядро сжимают (gzip, bzip2, lzma/xz, zstd), чтобы уменьшить размер образа и ускорить загрузку с диска. Распаковка происходит на раннем этапе загрузки (самораспаковывающийся образ). Скрипт `extract-vmlinux` позволяет извлечь несжатое ядро для анализа.
