**Практическая работа №1: Базовое использование ss**    

**Задание:**    
1. Показать все TCP соединения.    
2. Показать все UDP соединения.    
3. Показать все слушающие порты.    
4. Отфильтровать вывод только для IPv4.    
5. Отфильтровать вывод только для IPv6.    
6. Показать общее количество соединений.    

**Решение и пояснения:**
```bash
ss -t                         # 1. Все TCP соединения (установленные)
ss -u                         # 2. Все UDP соединения
ss -l                         # 3. Все слушающие (LISTEN) порты
ss -4                         # 4. Только IPv4 соединения
ss -6                         # 5. Только IPv6 соединения
ss -s                         # 6. Статистика: общее количество соединений
```
**Пояснения:**     
`ss` (socket statistics) — современная замена утилите `netstat`.     
Ключ 
`-t` показывает TCP, 
`-u` — UDP, 
`-l` — слушающие сокеты. 
`-4` и 
`-6` фильтруют по версии IP.     
`-s` выводит сводную статистику по типам соединений.

**Практическая работа №2: Детальный анализ соединений**    

**Задание:**    
1. Показать TCP соединения с процессом, который их использует.    
2. Показать UDP порты с именами процессов.    
3. Показать все соединения в числовом формате (без DNS-разрешения).    
4. Отфильтровать соединения по порту (например, 22).    
5. Отфильтровать соединения по состоянию (например, ESTAB).    
6. Показать соединения с определенным удаленным адресом.    

**Решение и пояснения:**    
```bash
ss -tp                          # 1. TCP + процессы (-p)
ss -up                          # 2. UDP + процессы
ss -tn                          # 3. TCP в числовом формате (-n)
ss -t sport = :22               # 4. Фильтр по локальному порту 22
ss -t state established         # 5. Фильтр по состоянию
ss -t dst 8.8.8.8               # 6. Соединения с удаленным хостом
```
**Пояснения:**     
`-p` показывает PID и имя процесса.     
`-n` отключает преобразование портов в имена служб и IP в домены.     
Фильтры:     
`sport`/`dport` (источник/назначение порт),     
`src`/`dst` (источник/назначение IP),     
`state` (состояние). Состояния: ESTAB, LISTEN, TIME-WAIT и др.

**Практическая работа №3: Мониторинг и фильтрация**    

**Задание:**    
1. Показать все TCP соединения в состоянии LISTEN.    
2. Показать все установленные TCP соединения.    
3. Показать соединения в состоянии TIME-WAIT.    
4. Показать соединения, использующие более 1MB памяти.    
5. Отсортировать вывод по используемой памяти.    
6. Показать соединения определенного процесса по его PID.    

**Решение и пояснения:**    
```bash
ss -t state listening           # 1. TCP в состоянии LISTEN
ss -t state established         # 2. Установленные TCP соединения
ss -t state time-wait           # 3. Соединения в TIME-WAIT
ss -tm                          # 4. Показать использование памяти (-m)
ss -tm | sort -nk2              # 5. Сортировка по памяти
ss -p | grep pid=1234           # 6. Фильтр по PID (замените 1234)
```
**Пояснения:**     
`state listening` эквивалентно `-l` для TCP.     
`-m` показывает использование памяти сокетами в байтах.     
`sort -nk2` сортирует численно по второму столбцу (память).     
Фильтр по PID через `grep` удобен для анализа конкретного приложения.

**Практическая работа №4: Сравнение и расширенное использование**    

**Задание:**    
1. Сравните вывод `ss` и `netstat` для TCP портов.    
2. Показать все RAW сокеты (используемые ping, traceroute).    
3. Показать UNIX-сокеты (межпроцессное взаимодействие).    
4. Показать информацию о сетевых интерфейсах.    
5. Сохранить вывод ss в файл для последующего анализа.     
6. Написать скрипт для мониторинга новых соединений на порту 22.    

**Решение и пояснения:**
```bash
ss -t; echo "---"; netstat -t   # 1. Сравнение вывода
ss -raw                         # 2. RAW сокеты (используются ICMP)
ss -x                           # 3. UNIX сокеты
ss -i                           # 4. Информация о интерфейсах
ss -tuln > connections_$(date +%Y%m%d).log  # 5. Сохранение в файл
# 6. Скрипт monitor_ssh.sh:
while true; do
  ss -t sport = :22 | grep -v "State" | wc -l
  sleep 5
done
```
**Пояснения:**     
`ss` быстрее `netstat` и показывает больше информации. 
`-raw` показывает RAW сокеты (протоколы без транспортного уровня).     
`-x` показывает UNIX доменные сокеты для IPC.     
`-i` показывает статистику по интерфейсам.     
Скрипт мониторинга может детектировать подозрительную активность на SSH порту.
