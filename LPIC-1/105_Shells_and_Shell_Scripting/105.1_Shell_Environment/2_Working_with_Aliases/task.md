**Практическая работа №1: Базовые алиасы в сессии**

**Задание:**      
1. В текущей сессии терминала создайте алиас `ll` для команды `ls -alF`.      
2. Создайте алиас `..` для команды `cd ..`.      
3. Создайте алиас `clean` для команды очистки терминала `clear`.      
4. Проверьте работу всех созданных алиасов.      
5. Выведите список всех алиасов текущей сессии.      
6. Удалите алиас `clean` из текущей сессии.      
    

**Решение и пояснения:**
```bash
alias ll='ls -alF'       # 1. Подробный список с классификаторами
alias ..='cd ..'         # 2. Быстрый переход на уровень выше
alias clean='clear'      # 3. Алиас для очистки экрана
ll                       # 4. Проверка - покажет подробный список
..                       # 4. Перейдет в родительский каталог
clean                    # 4. Очистит экран
alias                    # 5. Выведет все активные алиасы
unalias clean            # 6. Удаление алиаса clean
```
**Пояснения:**       
Алиасы создаются командой `alias имя='команда'`.       
Они работают только в текущей сессии терминала.       
`alias` без аргументов показывает все алиасы.       
`unalias` удаляет алиас.

**Практическая работа №2: Постоянные алиасы в ~/.bashrc**

**Задание:**      
1. Откройте файл `~/.bashrc` в текстовом редакторе.      
2. Добавьте в конец файла алиас `update` для команды `sudo apt update && sudo apt upgrade -y`.      
3. Добавьте алиас `ports` для команды `netstat -tulpn`.      
4. Примените изменения без перезагрузки системы.      
5. Проверьте работу новых алиасов.      
6. Убедитесь, что алиасы сохраняются после перезапуска терминала.      

**Решение и пояснения:**
```bash
nano ~/.bashrc                     # 1. Открываем файл конфигурации
# Добавляем в конец файла:
alias update='sudo apt update && sudo apt upgrade -y'  # 2
alias ports='netstat -tulpn'       # 3
source ~/.bashrc                   # 4. Применяем изменения
update                             # 5. Проверяем (запрос пароля)
ports                              # 5. Проверяем список портов
```
**Пояснения:** 
`~/.bashrc` загружается при каждом запуске bash.       
`source ~/.bashrc` применяет изменения немедленно. Алиасы с sudo запросят пароль. После перезапуска терминала алиасы останутся.

**Практическая работа №3: Алиасы с аргументами**

**Задание:**       
1. Создайте алиас `mkd` для создания директории и немедленного перехода в неё.       
2. Создайте алиас `search` для поиска файлов по имени в текущем каталоге.       
!------Создайте алиас `searchlike` для поиска файлов по фрагменту имени       
!------Создайте алиас `cat file | less` для поиска файлов по фрагменту имени       
3. Создайте алиас `backup` для создания резервной копии файла с добавлением даты.       
4. Проверьте работу каждого алиаса с тестовыми данными.       
5. Добавьте эти алиасы в `~/.bashrc` для постоянного использования.       

**Решение и пояснения:**       
```bash
mkd() { mkdir -p "$1" && cd "$1"; }                 # 1. Создает и переходит
alias search='find . -name'                         # 2. Поиск от текущего каталога
alias backup='cp -v $1 $1.$(date +%Y%m%d).bak'      # 3. Копия с датой 
!---- не пашет. сделать с копий даты и времени

# Проверка:
mkd test_folder        # 4. Создает test_folder и переходит в него
search "*.txt"         # 4. Ищет txt-файлы
backup document.txt    # 4. Создает document.txt.20241225.bak
```
**Пояснения:**        
Для алиасов с аргументами используйте функции (более гибко) или указывайте позиции `$1`.        
`date +%Y%m%d` дает дату в формате ГГГГММДД. `-p` в mkdir создает промежуточные каталоги.

**Практическая работа №4: Управление и отладка алиасов**

**Задание:**       
1. Создайте алиас `myaliases` для вывода всех ваших алиасов в формате "Алиас -> Команда".       
2. Создайте алиас `editbash` для быстрого редактирования `~/.bashrc` в nano.       
3. Создайте алиас `reload` для применения изменений `.bashrc`.       
4. Проверьте, не переопределяют ли ваши алиасы стандартные команды.       
5. Временно отключите все алиасы для одной команды.       
6. Создайте резервную копию вашего `.bashrc` с помощью алиаса.       

**Решение и пояснения:**
```bash
# Добавляем в ~/.bashrc:
alias myaliases='alias | grep -E "^alias\s+"'        # 1. Фильтрованный вывод
alias editbash='nano ~/.bashrc'                      # 2. Быстрый доступ
alias reload='source ~/.bashrc'                      # 3. Перезагрузка

# Проверка:
myaliases                    # 4. Покажет все алиасы
type ls                      # 4. Проверяем, не переопределен ли ls
\ls                          # 5. Временное отключение алиасов для ls
cp ~/.bashrc ~/.bashrc.backup.$(date +%Y%m%d)        # 6. Резервная копия
```
**Пояснения:**        
`alias | grep` фильтрует вывод только алиасов.        
`type` показывает, чем является команда (алиас/функция/бинарник).        
`\command` игнорирует алиасы. Резервные копии конфигов — хорошая практика.
