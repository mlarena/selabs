**Практическая работа №1: Работа с разделами (fdisk)**

**Задание:**
1. Создайте файл-образ диска размером 100 МБ.
2. Подключите его как loop-устройство.
3. Разметьте его на два раздела через `fdisk`.
4. Выведите таблицу разделов.
5. Объясните разницу между MBR и GPT.

**Решение и пояснения:**
```bash
dd if=/dev/zero of=~/disk.img bs=1M count=100     # 1. Образ диска
sudo losetup -fP ~/disk.img                        # 2. Loop-устройство
losetup -l | grep disk.img                         # 2. Имя /dev/loopX
sudo fdisk /dev/loop0                              # 3. n - новый, w - записать
sudo fdisk -l /dev/loop0                           # 4. Таблица разделов
```
**Пояснения:**
`losetup` позволяет работать с файлом как с блочным устройством. `fdisk` создаёт таблицу разделов (по умолчанию MBR). MBR поддерживает до 4 основных разделов и диски до 2 ТБ; GPT — до 128 разделов и диски больше 2 ТБ, а также резервную копию таблицы.

**Практическая работа №2: Создание файловых систем**

**Задание:**
1. Создайте раздел на loop-устройстве.
2. Создайте на нём файловую систему ext4.
3. Создайте вторую ФС — XFS.
4. Создайте swap-раздел.
5. Посмотрите типы созданных ФС.

**Решение и пояснения:**
```bash
sudo mkfs.ext4 /dev/loop0p1        # 2. ext4
sudo mkfs.xfs /dev/loop0p2         # 3. XFS
sudo mkswap /dev/loop0p3           # 4. swap
blkid /dev/loop0p1 /dev/loop0p2    # 5. Тип и UUID
```
**Пояснения:**
`mkfs.<тип>` создаёт файловую систему нужного типа. `mkfs.ext4` — журналируемая ФС для корня и данных; `mkfs.xfs` — высокопроизводительная ФС; `mkswap` создаёт область подкачки. `blkid` показывает тип ФС и UUID.

**Практическая работа №3: GPT и parted**

**Задание:**
1. Создайте GPT-таблицу на loop-устройстве через `parted`.
2. Создайте раздел от 1 МБ до 50 МБ.
3. Помеченный как EFI System Partition.
4. Создайте раздел ext4 в остатке.
5. Выведите таблицу разделов.

**Решение и пояснения:**
```bash
sudo parted /dev/loop0 mklabel gpt                 # 1. GPT
sudo parted /dev/loop0 mkpart primary fat32 1MiB 50MiB   # 2-3. ESP
sudo parted /dev/loop0 set 1 esp on                # 3. Флаг ESP
sudo parted /dev/loop0 mkpart primary ext4 50MiB 100%    # 4
sudo parted /dev/loop0 print                       # 5. Таблица
```
**Пояснения:**
`parted` умеет работать с GPT. `mklabel gpt` создаёт GPT-таблицу. Раздел с флагом `esp` — EFI System Partition (FAT32), используемый для загрузки UEFI. `mkpart` создаёт раздел с указанием начала и конца в единицах (MiB, %).

**Практическая работа №4: Swap-файл и монтирование**

**Задание:**
1. Создайте swap-файл размером 64 МБ.
2. Подключите его как swap.
3. Проверьте активные области подкачки.
4. Смонтируйте созданную ФС во временный каталог.
5. Отключите swap и размонтируйте ФС.

**Решение и пояснения:**
```bash
sudo fallocate -l 64M /swapfile      # 1. Swap-файл
sudo chmod 600 /swapfile
sudo mkswap /swapfile                # 2. Форматирование
sudo swapon /swapfile                # 2. Включение
swapon --show                        # 3. Активные области
sudo mkdir -p /mnt/test && sudo mount /dev/loop0p1 /mnt/test   # 4
sudo swapoff /swapfile               # 5. Отключение
sudo umount /mnt/test                # 5. Размонтирование
```
**Пояснения:**
Swap можно размещать не только в разделе, но и в файле. `fallocate` создаёт файл нужного размера, `mkswap` размечает, `swapon`/`swapoff` включают/отключают. `mount`/`umount` подключают и отключают файловые системы.
