**Практическая работа №1: Базовое использование lsof**    

**Задание:**    
1. Показать все открытые файлы в системе.    
2. Показать файлы, открытые конкретным процессом (например, `sshd`).    
3. Показать файлы, открытые конкретным пользователем.    
4. Найти процесс, который использует определенный файл.    
5. Показать все открытые сетевые файлы (сокеты).    
6. Показать файлы, открытые в определенном каталоге.    
    
**Решение и пояснения:**
```bash
sudo lsof                        # 1. Все открытые файлы (очень много вывода)
sudo lsof -c sshd                # 2. Файлы процесса sshd
sudo lsof -u user1               # 3. Файлы пользователя user1
sudo lsof /var/log/syslog        # 4. Кто использует файл syslog
sudo lsof -i                     # 5. Все сетевые соединения
sudo lsof +D /var/log            # 6. Файлы в каталоге /var/log
```

**Пояснения:**     
`lsof` (list open files) показывает открытые файлы,     
включая обычные файлы, каталоги, библиотеки, сетевые сокеты. `-c` фильтрует по имени команды, `-u` — по пользователю. `-i` показывает сетевые файлы. `+D` рекурсивно ищет в каталоге. Без sudo не все файлы будут видны.

**Практическая работа №2: Работа с сетевыми соединениями**

**Задание:**      
1. Показать все TCP соединения.      
2. Показать все UDP соединения.      
3. Найти процесс, использующий определенный порт (например, 80).      
4. Показать соединения на определенном интерфейсе (например, eth0).      
5. Показать все IPv6 соединения.      
6. Найти все соединения с определенным удаленным хостом.      

**Решение и пояснения:**
```bash
sudo lsof -i TCP                 # 1. Все TCP соединения
sudo lsof -i UDP                 # 2. Все UDP соединения
sudo lsof -i :80                 # 3. Кто использует порт 80
sudo lsof -i @192.168.1.1        # 4. Соединения на интерфейсе с IP
sudo lsof -i 6                   # 5. IPv6 соединения (6 = IPv6)
sudo lsof -i @google.com         # 6. Соединения с google.com
```
**Пояснения:**       
`-i TCP`/`-i UDP` фильтруют по протоколу.       
`-i :порт` ищет по номеру порта.       
`-i @адрес` фильтрует по IP или доменному имени.       
`-i 6` — IPv6,       
`-i 4` — IPv4. lsof автоматически разрешает DNS имена, если не указать `-n`.

**Практическая работа №3: Анализ процессов и дескрипторов**

**Задание:**      
1. Показать все открытые файлы процесса по его PID.      
2. Показать только дескрипторы файлов (FD) определенного типа.      
3. Найти все процессы, использующие определенную библиотеку (.so файл).      
4. Показать все открытые файлы определенного типа (например, txt).      
5. Найти процессы с большим количеством открытых файлов.      
6. Освободить занятый файл (убить процесс).      

**Решение и пояснения:**
```bash
sudo lsof -p 1234                # 1. Файлы процесса с PID 1234
sudo lsof -p 1234 -d txt         # 2. Только текстовые дескрипторы процесса
sudo lsof /usr/lib/*.so          # 3. Процессы, использующие библиотеки
sudo lsof -c apache | grep '.txt$'  # 4. Текстовые файлы процесса apache
sudo lsof | awk '{print $1}' | sort | uniq -c | sort -nr | head -10  # 5. Топ процессов
sudo lsof /path/to/locked/file   # 6. Найти и завершить: sudo kill -9 PID
```
**Пояснения:**       
`-p PID` фильтрует по идентификатору процесса.       
`-d` фильтрует по дескрипторам (txt, mem, cwd и др.). grep помогает фильтровать по расширению.       
Команда с `awk` и `uniq` подсчитывает файлы на процесс.       
Чтобы освободить файл, нужно завершить процесс, который его держит.

**Практическая работа №4: Мониторинг и диагностика проблем**      
      
**Задание:**            
1. Найти все удаленные файлы, которые все еще открыты процессами.      
2. Показать файлы, открытые для записи.      
3. Найти утечку файловых дескрипторов (много открытых файлов).      
4. Показать все открытые файлы файловой системы /var.      
5. Создать скрипт для мониторинга открытых сетевых портов.      
6. Написать команду для поиска скрытых сетевых соединений.      

**Решение и пояснения:**
```bash
sudo lsof +L1                    # 1. Удаленные файлы (link count < 1)
sudo lsof -a -c sshd -d w        # 2. Файлы открытые для записи (-d w)
sudo lsof -p $(pidof process) | wc -l  # 3. Подсчет файлов процесса
sudo lsof /var                   # 4. Файлы в файловой системе /var
# 5. Скрипт monitor_ports.sh:
sudo lsof -i -P -n | grep LISTEN | awk '{print $9,$1}' | sort
# 6. Поиск скрытых соединений:
sudo lsof -i -P -n | grep -v "ESTABLISHED\|LISTEN"
```
**Пояснения:**       
`+L1` показывает файлы с счетчиком ссылок меньше 1 (удаленные, но открытые).       
`-a` означает AND (логическое И) между фильтрами.       
`-P -n` отключает преобразование портов и имен хостов для скорости.       
Скрытые соединения — не в состояниях ESTABLISHED/LISTEN.       
Скрипты помогают автоматизировать мониторинг.
