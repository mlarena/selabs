**Практическая работа №1: Знакомство с RPM на Debian**

**Задание:**
1. Установите пакет `rpm` (утилита для работы с RPM-пакетами).
2. Скачайте любой небольшой RPM-пакет.
3. Выведите информацию о пакете (имя, версию, описание).
4. Покажите список файлов внутри RPM-пакета.
5. Проверьте зависимости пакета.

**Решение и пояснения:**
```bash
sudo apt install -y rpm alien
wget -O /tmp/hello.rpm http://rpmfind.net/linux/.../hello.rpm   # 2. Пример
rpm -qpi /tmp/hello.rpm      # 3. Информация о пакете (-q query, -p package, -i info)
rpm -qpl /tmp/hello.rpm      # 4. Список файлов (-l list)
rpm -qpR /tmp/hello.rpm      # 5. Зависимости (-R requires)
```
**Пояснения:**
На Debian утилита `rpm` умеет читать RPM-пакеты без установки. Ключи: `-q` запрос, `-p` работа с файлом пакета, `-i` информация, `-l` файлы, `-R` зависимости.

**Практическая работа №2: Извлечение файлов из RPM**

**Задание:**
1. Извлеките содержимое RPM-пакета без установки.
2. Преобразуйте RPM в DEB с помощью `alien`.
3. Установите полученный DEB-пакет.
4. Удалите пакет.
5. Опишите, почему конвертация RPM в DEB не всегда безопасна.

**Решение и пояснения:**
```bash
mkdir /tmp/rpm_extract && cd /tmp/rpm_extract
rpm2cpio /tmp/hello.rpm | cpio -idmv      # 1. Извлечение
sudo alien -d /tmp/hello.rpm              # 2. Конвертация в .deb
sudo dpkg -i /tmp/hello_*.deb             # 3. Установка
sudo apt remove -y hello                  # 4. Удаление
```
**Пояснения:**
`rpm2cpio` превращает RPM в поток cpio, который распаковывается в текущий каталог. `alien -d` конвертирует в DEB. Конвертация может нарушить зависимости и пути, поэтому её применяют только при отсутствии нативной сборки.

**Практическая работа №3: Сравнение менеджеров пакетов (концептуально)**

**Задание:**
1. Запишите команду установки пакета в apt, yum/dnf и zypper.
2. Запишите команду поиска пакета в apt и dnf.
3. Запишите команду обновления всех пакетов в apt и dnf.
4. Укажите, где хранятся конфигурации репозиториев в Debian и RHEL.
5. Объясните назначение `dnf` относительно `yum`.

**Решение и пояснения:**
```text
Установка:   apt install <pkg>   | dnf install <pkg>   | zypper install <pkg>
Поиск:       apt search <pkg>    | dnf search <pkg>
Обновление:  apt update && apt upgrade  | dnf upgrade
Репозитории: /etc/apt/sources.list(.d/) | /etc/yum.repos.d/*.repo
```
**Пояснения:**
`yum` — старый менеджер RHEL, `dnf` — его современная замена (Python 3, лучшее разрешение зависимостей). Команды во многом совместимы. На Debian основным менеджером остаётся `apt`/`dpkg`.

**Практическая работа №4: Проверка целостности и подписей**

**Задание:**
1. Проверьте цифровую подпись RPM-пакета.
2. Выведите контрольные суммы файлов пакета.
3. Проверьте целостность установленных в системе RPM (если есть).
4. Покажите ключи RPM, импортированные в систему.
5. Объясните разницу между проверкой подписи и контрольной суммы.

**Решение и пояснения:**
```bash
rpm -K /tmp/hello.rpm        # 1. Проверка подписи/дайджеста (-K checksig)
rpm -qp --dump /tmp/hello.rpm | head   # 2. Контрольные суммы файлов
rpm -Va                     # 3. Проверка всех установленных RPM
rpm -qa gpg-pubkey*         # 4. Импортированные ключи
```
**Пояснения:**
`rpm -K` проверяет криптографическую подпись пакета (подлинность источника). Контрольные суммы (`--dump`) проверяют целостность файлов. `rpm -Va` сравнивает установленные файлы с метаданными пакета. На чистом Debian RPM-базы нет, поэтому часть команд демонстрационная.
