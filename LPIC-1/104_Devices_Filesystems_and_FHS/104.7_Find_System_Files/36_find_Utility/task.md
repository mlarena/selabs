**Практическая работа №1: Базовый поиск файлов**

**Задание:**
1. Найдите все файлы с расширением `.conf` в директории `/etc`.       
2. Найдите все файлы, измененные за последние 24 часа.       
3. Найдите все скрытые файлы (начинающиеся с точки) в домашней директории.       
4. Найдите пустые файлы и директории.       
5. Найдите файлы, принадлежащие определенному пользователю.       
6. Найдите файлы по размеру (больше 100MB).       

**Решение и пояснения:**
```bash
# 1. Файлы .conf в /etc
find /etc -name "*.conf" 2>/dev/null | head -10

# 2. Измененные за последние 24 часа
find /home -mtime -1 2>/dev/null | head -5

# 3. Скрытые файлы
find ~ -name ".*" -type f 2>/dev/null | head -5

# 4. Пустые файлы и директории
find /tmp -empty 2>/dev/null

# 5. Файлы пользователя user1
find /home -user user1 2>/dev/null | head -5

# 6. Файлы >100MB
find / -size +100M 2>/dev/null | head -5
```
**Пояснения:**        
`find` ищет файлы по различным критериям.        
`-name` ищет по имени,        
`-type f` — только файлы,        
`-type d` — директории.        
`-mtime -1` — модифицированные за последний день.        
`-size +100M` — размер больше 100MB.        
`2>/dev/null` скрывает ошибки доступа.

**Практическая работа №2: Поиск с действиями**       

**Задание:**              
1. Найдите файлы `.log` и удалите их.       
2. Найдите файлы с правами 777 и измените их на 644.       
3. Найдите все символические ссылки и выведите их цели.       
4. Найдите файлы, содержащие определенный текст.       
5. Найдите и архивируйте все файлы `.txt`.          
6. Найдите и посчитайте количество файлов в директории.            

**Решение и пояснения:**
```bash
# 1. Удаление .log файлов в /tmp
find /tmp -name "*.log" -delete 2>/dev/null

# 2. Изменение прав с 777 на 644
find /home -perm 777 -exec chmod 644 {} \; 2>/dev/null

# 3. Символические ссылки
find /usr/bin -type l -exec ls -l {} \; 2>/dev/null | head -5

# 4. Файлы, содержащие "ERROR"
find /var/log -type f -exec grep -l "ERROR" {} \; 2>/dev/null | head -5

# 5. Архивирование .txt файлов
find ~ -name "*.txt" -exec tar -czf txt_backup.tar.gz {} + 2>/dev/null

# 6. Подсчет файлов
find /etc -type f | wc -l
```
**Пояснения:** `-exec` выполняет команду для каждого найденного файла. `{}` заменяется на имя файла. `\;` завершает команду. `-delete` удаляет найденные файлы. `grep -l` показывает только имена файлов с совпадением. `wc -l` считает строки (количество файлов).

**Практическая работа №3: Комбинированные условия поиска**

**Задание:**
1. Найдите файлы, измененные между двумя датами.
2. Найдите файлы определенного типа (например, JPEG).
3. Исключите определенные директории из поиска.
4. Найдите файлы, доступные для записи всем.
5. Найдите файлы, к которым не обращались более 30 дней.
6. Найдите файлы по нескольким расширениям.

**Решение и пояснения:**
```bash
# 1. Измененные с 1 по 10 января 2024
find /home -newermt "2024-01-01" ! -newermt "2024-01-10" 2>/dev/null | head -5

# 2. JPEG файлы
find ~ -type f \( -name "*.jpg" -o -name "*.jpeg" \) 2>/dev/null | head -5

# 3. Исключение директорий
find /home -type f -not -path "*/tmp/*" -not -path "*/.cache/*" 2>/dev/null | head -5

# 4. Файлы, доступные для записи всем
find /home -perm -o=w 2>/dev/null | head -5

# 5. Неиспользуемые файлы (>30 дней)
find /var/log -atime +30 2>/dev/null | head -5

# 6. Несколько расширений
find ~ -type f \( -name "*.txt" -o -name "*.md" -o -name "*.doc" \) 2>/dev/null | head -5
```
**Пояснения:**       
`-newermt` ищет по дате модификации.        
`-o` означает ИЛИ.      
`-not -path` исключает пути.      
`-perm -o=w` ищет файлы, доступные для записи другими (others).         
`-atime +30` — доступ не позже 30 дней назад.        
Группировка условий через `\( ... \)`.

**Практическая работа №4: Практические задачи мониторинга**     

**Задание:**    
1. Найдите 10 самых больших файлов в системе.      
2. Найдите бинарные файлы без дебаг-символов.      
3. Найдите дубликаты файлов по содержимому.      
4. Найдите сломанные символические ссылки.      
5. Создайте скрипт для ежедневного поиска новых файлов.     
6. Мониторьте изменения в критических директориях.      

**Решение и пояснения:**
```bash
# 1. 10 самых больших файлов
find / -type f -exec du -h {} + 2>/dev/null | sort -rh | head -10

# 2. Бинарные файлы (не текстовые)
find /usr/bin -type f -exec file {} \; | grep "ELF" | head -5

# 3. Поиск дубликатов по MD5
find ~ -type f -exec md5sum {} + 2>/dev/null | sort | uniq -w32 -dD

# 4. Сломанные символические ссылки
find / -type l ! -exec test -e {} \; -print 2>/dev/null | head -5

# 5. Скрипт для новых файлов за день
#!/bin/bash
find /home -type f -mtime -1 > new_files_$(date +%Y%m%d).log

# 6. Мониторинг изменений в /etc
find /etc -type f -mmin -60 2>/dev/null
```
**Пояснения:**     
`du -h` показывает размер файлов в human-readable формате.      
`file` определяет тип файла.     
Поиск дубликатов через `md5sum` и `uniq -d`.       
`! -exec test -e` находит несуществующие цели симлинков.      
Мониторинг по времени (`-mmin -60` — изменения за последний час) полезен для безопасности.
